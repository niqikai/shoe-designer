# M1 实心造型报告

首次构建：2026-10-07；验收检查更新：2026-10-08。用户确认“右脚、低帮 75 mm”后，以 v001 参数构建实心整鞋。M1 输出已完成，等待用户看图确认后进入 M2；原始鞋楦与衍生网格均仅保留在本机。

## 本轮设计

| 项目 | 本轮值 |
| --- | --- |
| 左右脚、鞋口 | 右脚，低帮 75 mm |
| 名义尺码、脚宽 | EU 42，标准宽度 |
| 鞋头 | 保留基准圆度与高度，均无局部增减 |
| 脚跟、前掌底厚 | 24 mm、16 mm |
| 外底外扩、边缘圆角 | 6 mm、2 mm |
| 鞋面围条目标厚度 | 2.4 mm |
| 中底、外底基底 | 实心中底，底层 3 mm 为外底色区 |
| 体素间距 | 1 mm |

鞋口高度相对规范化楦底基准。脚跟、前掌底厚分别在楦长 15% 和 72% 附近的中线采样点，从楦底到最下底面垂直计量。EU 42 是工程基码假设，尚未经量脚与试穿验证。

## 已实现的造型

- 从变形后的高模提取底部轮廓，向外扩出板鞋底；边缘圆角可调。
- 实心中底顶面贴合高模楦底曲面，保留足弓起伏；外扩肩部使用实测底／侧过渡线延伸，已处理预览中边缘高度噪声。
- 鞋面向楦外偏移，内侧保持空腔，在 75 mm 形成实际鞋口；鞋口材料边缘闭合，整鞋材料实体封闭。
- 非等比尺码变化、窄／标准／宽脚、鞋头圆度与局部高度；形变后重新提取特征并检查。
- 同一右脚基准镜像生成左脚，并保持外向法线。
- 鞋底、实心中底、鞋面合并为单个连接实体；预览颜色表示区域，不代表多材料打印。

## 测试与后续验收

测试入口（先生成默认 M1 导出）：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -p 'test_*.py' -v
blender -b --factory-startup --disable-autoexec --python-exit-code 1 --python tests/blender_last_tests.py
blender -b --factory-startup --disable-autoexec --python-exit-code 1 --python tests/blender_deform_tests.py
blender -b --factory-startup --disable-autoexec --python-exit-code 1 --python tests/blender_shoe_tests.py -- --stress
```

已验证 STL 重新导入后仍封闭且毫米尺寸一致；GLB 按世界变换转回毫米后与 STL 边界一致（检查容差 0.002 mm），保留三个使用中的材质区域。鞋口三处向下射线可直接到达鞋垫，九处足弓采样及两处底厚与目标相符（检查容差 1.25 mm）。左右镜像保持体积、尺寸和外向法线。

四个整鞋边界组合覆盖 EU35／46、窄／宽脚、低帮 60／85 与中帮 115 mm、最薄鞋面、最大底厚／圆角和鞋头联合限幅，其中包含左脚。测试只验证几何与导出，1000 组随机组合留待 M5。

测试汇总：参数与启动器 11 项、M0.5 回归 9 项、受控形变 7 项、整鞋集成 8 项（含四组边界构造），共 35 项。日志保存在本机 `out/m1-last-regression.log`、`out/m1-deform-tests.log`、`out/m1-tests.log`；每次正常生成也保存 `out/logs/build-*.log`。

M2 加入分区晶格，M3 验证制造壁厚、杆径、悬垂、排粉与构建尺寸，M4 完成自动修改和撤销闭环，M5 完成批量参数测试。现阶段不承诺合脚性或力学性能；进入制造试样时建议先验证脚跟局部样件。
