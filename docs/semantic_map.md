# 自然语言与参数映射

参数规则按里程碑上线。当前 M0.5 只控制鞋楦裁切，几何由 `build_shoe(params)` 自动处理。

| 用户表达 | 参数修改 | 说明 |
| --- | --- | --- |
| 低帮／鞋口低一些（明确切换款型时） | `collar_style=low`，初始候选 `collar_height_mm=75` | 尚待用户确认；按低帮范围截断 |
| 中帮／鞋口高一些（明确切换款型时） | `collar_style=mid`，初始候选 `collar_height_mm=100` | 尚待用户确认；按中帮范围截断 |
| 鞋口提高／降低 N 毫米 | 在当前 `collar_height_mm` 上加／减 N | 保持款型；超范围截断并说明结果 |

“圆头”“厚底”“回弹好”“轻”“稳”“透气”等规则将在 M1／M2 对应参数实现时集中补充。性能描述只给预估倾向，不承诺。新表达先查此表，缺失时记录推断依据；每次真实修改先备份当前设计并追加变更原因。
