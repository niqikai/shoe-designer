# #10 用鞋楦重建鞋内腔:技术方案

状态:方案(未实现)。对应 issue #10,是 #9 Gate 的证据来源。
范围:单款模板(DLP 43 码右脚)+ Zellerfeld Sneaker 鞋楦,单码。不含图案/镂空(#13),不含打印实测(#11),也不含通用校验模块(#12)。

- 每侧需要的空间是"松量 + 壁厚"约 1 + 2 = 3 mm,两侧合计约 6 mm。镂空款鞋头、实心款后跟和跖围的余量都只有 5.5–6.7 mm,处在临界状态;再加上鞋楦和模板的轮廓不完全相似,**局部一定会出现壁厚不足**。因此"补壁/推外表皮"是必须做的一步,不是例外处理。
- 鞋楦底面不平:后跟抬高约 11 mm(跟高差),鞋头翘起约 4 mm。这和 #7 的结论一致:鞋楦"低位"放不进去。新内腔的地板直接取鞋楦底面加松量,不需要沿用模板的地板。

## 1. 几何做法

### 1.1 表示:在规则网格的带符号距离场(SDF)上做

所有体素运算都在一个共享的规则体素网格上完成(φ < 0 表示在内部):

- 体素:迭代时用 1.0 mm,出图用 0.4 mm(≤ 最小壁厚 1.2 mm 的 1/3,保证 marching cubes 的误差不会吞掉壁厚)。网格范围约 300 × 130 × 150 mm:1.0 mm 时约 5.9 M 个体素(float32 约 23 MB);0.4 mm 时约 91 M 个(约 370 MB,中间场再乘几倍)。因此出图时分块计算,或只在窄带内保存精确距离、窄带外只存符号。
- 网格转 SDF:距离用最近三角形(`libigl` 的 AABB 树),符号用**快速广义绕数**(fast winding number)。它对 100 万面的镂空网格、局部不水密的网格都稳定。
- SDF 转网格:用 `skimage.measure.marching_cubes`,网格四周留 2 个体素的空边,输出必然水密、无自相交;之后做一次 trimesh 清理和简化。
- 新增依赖:`libigl`、`scikit-image`(**决策点 D6**)。

选 SDF 的理由:和路线图(SDF 细节层,#13)用同一种表示;offset 就是对 φ 加常数,布尔运算就是取 min/max,天然不会自相交;壁厚、自支撑这类约束能写成对场的逐点运算,在构造时就成立。

### 1.2 几个场

| 符号 | 含义 | 怎么得到 |
|---|---|---|
| φ_L | 鞋楦 | 鞋楦网格转 SDF,并施加 §1.3 求出的位姿 |
| φ_E | 模板**外包络**(封住内腔和镂空后的实心外形) | §1.4 |
| e(x) | 松量场(按区平滑变化) | §4 |
| t(x) | 目标壁厚场 | 默认 2.0 mm,下限 1.2 mm |
| φ_T | 鞋口截断面(其上方为"外部") | §4.3 |

内腔:φ_C = φ_L − e(x),再并上鞋口上方的竖直挤出(§4.3),然后做自支撑闭包(§3),得到 φ_C*。

鞋体:

```
φ_E'  = 补壁后的外包络(§2)   保证 φ_E' ≤ φ_C* − t 在鞋口线以下处处成立
φ_shoe = max(φ_E', −φ_C*)       外包络减去内腔
```

### 1.3 鞋楦在模板里的位姿

鞋楦的形状不能改;能改的是鞋楦相对模板的刚体位姿,以及模板外包络的整体缩放(属于造型,允许)。

- 变量:dx, dy, dz, 俯仰角 pitch, 偏航角 yaw(±3°);可选模板各向异性缩放 sx, sy ∈ [0.97, 1.05]。
- 目标:在鞋楦表面采样点 p 上,定义缺口 deficit(p) = max(0, φ_E(p) + e(p) + t(p))(外表皮离鞋楦不够远的量)。最小化 Σ deficit² + λ·Σ 缩放偏离²。
- 约束:鞋楦脚掌最低点到打印床的距离 ≥ 最小底厚 s_min(默认 6 mm,参照 Zellerfeld 的鞋底约 8 mm,**决策点 D4**)。
- 求解:φ_E 用三线性插值查询,开销很小;先粗网格搜索再用 Nelder–Mead 细化。这一步替代 #7 中只做平移搜索的 `fit_to_last`。

### 1.4 外包络 φ_E

- 实心款:模板占据体素化后,**逐个 z 层做二维孔洞填充**(`scipy.ndimage.binary_fill_holes`)。在鞋口线以下,鞋壁在每一层都是闭合的一圈,内腔会被填实;鞋口线以上那一圈断开,不会被填。这样不需要知道鞋口线的确切形状。
- 镂空款:先做三维闭运算(半径 ≥ 最大镂空孔半径,先测量),再逐层填充。
- 镂空/格栅图案在 #10 里**不保留**:默认按实心外包络出图,图案交给 #13 的 SDF 细节层重新施加。也可以选择保留:φ_shoe 再与"原模板材料 ∪ 内衬层(内腔外 t_min 厚)"求交,鞋面保留原镂空、内侧有连续内衬。缺点是孔不再通透(**决策点 D2**)。

## 2. 壁厚不均、过薄、自相交

SDF 构造本身没有自相交:输出由 marching cubes 从单个场提取,天然水密、流形。所以这里要解决的只有壁厚。壁厚按三级处理,每一级都有判据:

1. **全局:位姿与缩放**(§1.3)。消化掉系统性的偏差。
2. **局部光滑推移**(相当于对外表皮做受约束的非刚性形变,但在隐式场上完成):
   缺口场 D(x) = max(0, φ_E − (φ_C* − t)),只在鞋口线以下、外包络附近的窄带内计算;
   φ_E' = φ_E − G_σ ∗ D(高斯平滑,σ 约 6–10 mm),外表皮在缺口周围被平滑地向外推。
   推移量和面积都会进报告。
3. **硬补壁兜底**:φ_E'' = smin(φ_E', φ_C* − t_min, k)(平滑并集,k 约 2 mm)。这一步保证每处壁厚 ≥ t_min,并且只在鞋口线以下生效。

判据(写入报告,也作为 #9 Gate 的输入):

| 指标 | 可接受 | 判定模板不适用 |
|---|---|---|
| 第 2 级推移量 p95 | ≤ 2 mm | 最大推移 > 4 mm |
| 被推移的外表皮面积 | ≤ 15% | > 30% |
| 第 3 级硬补壁面积 | ≤ 3% | > 10% |

"判定模板不适用"的含义:外形已经被改得不像原模板,模板路线对这一款不成立。回退顺序:先换模板(44 码或另一系列)重跑;所有模板都不适用时,#9 的 Gate 判失败,回到 **SDF 从零生成表皮**,即外表皮 = φ_C* − t(x) 再加造型偏移。本方案的 SDF 基础设施在回退路线里可以原样复用。

## 3. 悬垂:在构造时保证内腔自支撑

鞋底朝下打印时,内腔里朝下的面就是鞋面内侧的"天花板",也就是鞋头和鞋背的内侧。鞋楦脚尖附近的顶面接近水平(0.85 和 0.95 处顶高分别是 32.8 和 29.9),如果照原样做,就是一个约 60 mm 宽的水平悬空面。

**构造方法:对内腔做 45° 闭包。**从下往上逐层处理(层距 h = 体素尺寸):

```
V(z+h) = C(z+h) ∪ erode(V(z), h·tan α)      α = 45°(相对竖直方向)
```

意思是:内腔每升高 h,最多只能向内收 h·tan α,收得更快的部分会被补成空腔,形成"尖顶/穹顶"。在 SDF 上逐层写成 φ_V(z+h) = min(φ_C(z+h), φ_V(z) + h·tan α),最后整体重新计算距离。由于 V ⊇ C,闭包只会增加空腔,不会侵占鞋楦和松量的空间;天花板的每一点都有 ≤ 45° 的支撑。之后第 2 节的壁厚处理是相对 φ_C* 计算的,所以闭包把天花板抬高后,外表皮也会相应被推开,壁厚不受影响。

需要注意的副作用和对应处理:

- **鞋头顶部被抬高**:闭包相当于在内腔天花板上加一个屋脊。60 mm 宽时,最坏情况下屋脊高约 30 mm,实际上鞋楦顶面本身是圆的,增加量会小得多。需要在最小可行实验(MVE)里实测增加了多少。如果抬得太高,可以选择:允许 TPU 跨距 b(例如 ≤ 8 mm)以内的短桥接,或者把 α 放宽到 50°。这两个参数都要靠 #11 的打印实测来定(**决策点 D3**)。
- **后跟内收**:后跟在鞋口附近向内收,起包跟作用。闭包会把这部分削掉。如果后跟内收角度本身 ≤ 45°,闭包不会改动它;超出的部分在报告里单独列出"后跟包裹损失"。可以在后跟区域允许例外(内收部分很薄,TPU 可以桥接),也可以接受这部分损失(**决策点 D3**)。
- **外表皮的外悬垂**:外侧悬垂可以加外部支撑,事后能清掉,不属于 #10 要解决的问题,只要求补壁不让它变得更差(报告中对比 open_frac 的变化)。

**被否决的做法:**换打印朝向(侧放或倒放)。鞋底的质量和与打印床的附着都会变差,而且侧放时整个鞋面都会变成悬垂。双料可溶支撑:TPU 单喷头,而且内腔里的支撑仍然很难取出。

## 4. 松量与鞋口截断

### 4.1 松量建议(相对鞋楦表面的法向距离)

鞋楦本身已经包含了脚长余量(楦长大于脚长约 10–15 mm),所以这里的松量只用来抵消 TPU 打印误差和提供穿脱余量,不需要再按"脚到鞋"的松量来取。

| 区域 | 建议值 | 理由 |
|---|---|---|
| 鞋头(长度 0.85 以后) | +1.0 mm | 脚趾活动;顶部再由 45° 闭包额外增加 |
| 跖围两侧(0.60–0.85) | +0.5 mm | TPU 95A 有一定弹性,太松会滑脚 |
| 足弓与腰窝 | +0.5 mm | |
| 脚背(上表面 0.35–0.65) | +1.5 mm | 穿脱和系带空间;没有系带时需要更大 |
| 后跟(0–0.20) | +0.3 mm | 包跟,防止掉跟 |
| 地板(鞋楦底面) | +0.5 mm,另加鞋垫厚度 | 是否预留可拆鞋垫(3–4 mm)由**决策点 D1**决定 |
| FDM 收缩补偿 | 全局 +0.2 mm | 内孔打印出来通常偏小,数值待 #11 校准 |

分区定义在鞋楦的归一化坐标(长度比例、朝上/朝两侧/朝下的法向)上,区与区之间用 10 mm 宽的平滑过渡,得到连续的 e(x)。数值放在配置文件里,不写死在代码中。

### 4.2 壁厚目标

t = 2.0 mm(参考镂空款的中位数 2.6 mm);t_min = 1.2 mm(和审计阈值一致)。底部用 s_min 单独控制(§1.3)。

### 4.3 鞋口与鞋楦高出鞋口的部分

鞋楦高 136 mm,包括脚踝以上的楦柱;模板鞋口在后跟处约 95–105 mm。处理方法:

1. **鞋口线 φ_T**:默认沿用模板外包络自身的鞋口线(§1.4 逐层填充时,鞋壁那一圈在哪一层断开,鞋口就在哪里)。可选用 Zellerfeld 的 `ankle_height` 区域来校核高度(仅作内部参考)。
2. **内腔向上贯通**:取鞋楦在鞋口高度附近的水平截面,竖直挤出到网格顶部,与鞋楦求并集。这样可以保证内腔从鞋口完整穿出,不会因为楦柱前倾或后倾而在鞋口留下一圈薄膜。
3. **补壁只在鞋口线以下生效**:鞋口线以上不推外表皮,避免把楦柱的形状"长"成鞋帮。
4. **鞋口倒圆**:对鞋口边缘做 1.5 mm 的 SDF 圆角(先 offset 再反向 offset),消除磨脚的锐边,同时让最薄处远离 t_min。

## 5. 验证

### 5.1 复用和扩展 `shoe-assets audit`

| 指标 | 来源 | 通过标准 |
|---|---|---|
| 水密、单体 | `geometry` | watertight = True,bodies = 1 |
| 壁厚 | `wall_thickness` | frac_thin(< 1.2 mm)≤ 0.5%(只允许出现在鞋口圆角一带),p5 ≥ 1.5 mm |

| 带符号间隙 | `fit_to_last`,新增"固定位姿"模式 | 碰撞 = 0;间隙 ≥ e(x) − 0.3 mm(体素误差);分区间隙中位数与设定松量相差 ≤ 0.3 mm |

需要对审计做的两处扩展,都很小:

- `fit_to_last` 增加"给定位姿"模式:新鞋的位姿由构造时确定,不需要再搜索。
- 构造时记录每个面来自哪个场(哪个场在 min/max 中起作用:内腔 / 外表皮 / 补壁),据此把悬垂和壁厚按"内腔 / 外表皮 / 补壁"分开统计。现在"enclosed"的定义是"下方有材料",区分不出内腔天花板。

### 5.2 最小可行实验(MVE)

1. 输入:`dlp_solid_43_right`(没有镂空,外包络最好得到)和 `sneaker_last`;体素 1.0 mm,统一松量 1.0 mm,t = 2.0 mm。
2. 跑两组:不做 45° 闭包、做 45° 闭包,对比天花板增加的高度、外表皮被推移的量和各项指标。
3. 再换 `dlp_hollow_43_right` 跑一遍,外包络用闭运算得到。
4. 输出:STL、报告 JSON,以及截面图(长度 0.05 / 0.30 / 0.70 / 0.95 处)。
5. 打印验证(交给 #11,但 MVE 先准备好文件):只切出鞋头前 1/3 打印,验证天花板闭包和桥接,比打整只鞋快得多,也省料。

预计 MVE 需要 2–3 天(大部分时间在 SDF 基础设施和分块计算的性能上)。

## 7. 被否决的备选做法

| 做法 | 否决理由 |
|---|---|
| 复用并形变模板自带的内腔 | #7 已测得:最佳低位仍有 6–8% 表面碰撞,脚跟、鞋头、一侧和内底坡度同时没有松量;原内腔精度 ±2–4 mm,不够用 |
| 鞋楦网格沿顶点法向外扩得到内腔 | 凹处(足弓、脚踝)外扩后会自相交,外扩距离也不均匀 |
| 网格布尔运算(`manifold3d`:模板 − 外扩鞋楦) | 布尔本身稳健,但外扩、壁厚保证、自支撑都要另外实现;镂空款 100 万面,运算很重。保留作为 SDF 结果的交叉校验工具 |
| 对整只模板做 cage/ARAP 非刚性形变去贴合鞋楦 | 会把不可用的旧内腔一起带着变形;有自相交风险,需要额外检测;参数多且难调。§2 的"隐式场推移"已经做到了同样的效果 |
| 事后检查悬垂再打补丁 | 补丁位置不可控,可能在内腔里产生清不掉的支撑。改为在构造阶段用闭包保证 |
| 神经隐式场 / 学习方法 | v1 单码、单模板,用不上;没有训练数据 |
| 换打印朝向 / 可溶支撑 | 见 §3 |

## 8. 需要用户拍板的决策点

- **D1 松量与鞋垫**:§4.1 的分区数值是否接受;要不要预留 3–4 mm 的可拆鞋垫空间;成鞋是否有系带(影响脚背松量)。
- **D2 镂空**:#10 是只出实心外包络(推荐,图案交给 #13),还是保留原镂空并加内衬。
- **D3 悬垂规则**:内腔严格 45°,还是允许 ≤ b mm 的短桥接或放宽到 50°;后跟包裹是否允许例外。建议先按 45° 做,等 #11 实测后再放宽。
- **D4 厚度**:壁厚目标 2.0 / 下限 1.2 mm,鞋底最小厚度 6 mm,是否接受。
- **D5 打印机**:型号和成型空间。281 mm 长需要斜放,或者需要更大的打印机。
- **D6 新依赖**:是否接受引入 `libigl` 和 `scikit-image`。
- **D7 MVE 模板**:先用实心 43 码(推荐),再用镂空 43 码。
- **D8 Gate 阈值**:§2 判据表里"判定模板不适用"的数值,直接决定 #9 是否回退到 SDF 从零生成。
- **D9 Zellerfeld 区域文件**:是否允许用 `ankle_height` 和 `sole_thickness_region` 作内部参考(CC BY-NC-ND,产物不能分发)。
