## 1. 几何做法

### 1.1 表示:在规则网格的带符号距离场(SDF)上做

所有体素运算都在一个共享的规则体素网格上完成(φ < 0 表示在内部):

- 体素:迭代时用 1.0 mm,出图用 0.4 mm(≤ 最小壁厚 1.2 mm 的 1/3,保证 marching cubes 的误差不会吞掉壁厚)。网格范围约 300 × 130 × 150 mm:1.0 mm 时约 5.9 M 个体素(float32 约 23 MB);0.4 mm 时约 91 M 个(约 370 MB,中间场再乘几倍)。因此出图时分块计算,或只在窄带内保存精确距离、窄带外只存符号。
- 网格转 SDF:距离用最近三角形(`libigl` 的 AABB 树),符号用**快速广义绕数**(fast winding number)。它对 100 万面的镂空网格、局部不水密的网格都稳定。
- SDF 转网格:用 `skimage.measure.marching_cubes`,网格四周留 2 个体素的空边。这样的**原始输出**是水密、无自相交的。之后的处理:
  - 只保留最大连通分量,并在报告里记录丢掉的碎块体积。碎块体积 > 1 cm³ 视为构造错误,直接判失败,不悄悄丢掉。
  - 出图版本默认**不做简化**(0.4 mm 体素下约 2–4 M 面,切片软件可以处理)。确实需要简化时,简化后必须重跑完整 audit(水密、自相交、壁厚),并且简化误差 ≤ 0.1 mm。
  - 这里只保证"marching cubes 原始输出天然水密",之后每一步都靠 audit 复核,不再声称"天然成立"。
- 新增依赖:`libigl`、`scikit-image`(**决策点 D6**)。

选 SDF 的理由:和路线图(SDF 细节层,#13)用同一种表示;offset 就是对 φ 加常数,布尔运算就是取 min/max,天然不会自相交;壁厚、自支撑这类约束能写成对场的逐点运算,在构造时就成立。

### 1.2 几个场

| 符号 | 含义 | 怎么得到 |
|---|---|---|
| φ_L | 鞋楦 | 鞋楦网格转 SDF,并施加 §1.3 求出的位姿 |
| φ_E | 模板**外包络**(封住内腔和镂空后的实心外形) | §1.5 |
| e(x) | 松量场(按区平滑变化) | §4 |
| t(x) | 目标壁厚场 | 默认 2.0 mm;硬补壁 t_fill = 1.5 mm;审计下限 t_min = 1.2 mm |
| z_T(x, y) | 鞋口高度场(三维鞋口曲线插值成的曲面),给出"鞋口线以下"掩码 M_below | §1.5、§4.3 |

内腔:
- φ_C = φ_L − e(x),再按列向上贯通到鞋口(§4.3-2)。这一部分始终保持精确的距离值。
- 自支撑闭包(§3)新增的空腔 A 单独二值化得到 φ_A;合起来是 φ_C* = min(φ_C, φ_A)。

鞋体(各项的定义见 §2、§4.3):

```
φ_1 = φ_E − P_fit(cp(x))              第 2 级:针对合脚缺口的光滑推移
φ_2 = min(φ_1, φ_C − t_fill)           第 3 级:硬补壁(只在 M_below 内),计入 Gate
φ_3 = min(φ_2, φ_A − t)                闭包外壳:给屋脊包一层壳,不计入 Gate
φ_W = max(φ_3, −φ_C*)                  减去整个内腔
φ_shoe = max(roundI(φ_W, z − z_T, r), −z)   鞋口圆角求交,再按打印床平面裁一刀
```

鞋口线以下处处满足 φ_shoe 的壁厚 ≥ t_fill(相对 φ_C)或 ≥ t(相对 A)。

### 1.4 构造余量原则

构造用的参数**不能正好等于审计阈值或几何临界值**,否则能不能通过就取决于浮点误差和离散误差。统一的规则是:构造比审计多留一个体素量级的余量。

| 参数 | 审计 / 临界值 | 构造取值 |
|---|---|---|
| 最小壁厚 | t_min = 1.2 mm(audit `THIN_MM`) | t_fill = 1.5 mm(≥ t_min + 0.5 mm 的 1 mm 体素误差) |
| 悬垂角 | 45°(audit `OVERHANG_NZ`) | α_b = 43° |
| 鞋口圆角半径 | 壁厚 T 的一半 | 用圆角求交,不靠腐蚀;r = 1.0 mm |
| 平滑核 | 最大值滤波半径 R | 高斯核截断半径 ≤ R |

### 1.3 鞋楦在模板里的位姿

鞋楦的形状不能改;能改的是鞋楦相对模板的刚体位姿,以及模板外包络的整体缩放(属于造型,允许)。

- 变量:dx, dy, dz, 俯仰角 pitch, 偏航角 yaw(±3°);可选模板各向异性缩放 sx, sy ∈ [0.97, 1.05]。
- 目标:在鞋楦表面采样点 p 上,定义缺口 deficit(p) = max(0, φ_E(p) + e(p) + t(p))(外表皮离鞋楦不够远的量)。**只对 M_below 内的采样点求和**:鞋口以上的楦柱 deficit 有几十 mm,算进去会让优化器只顾把鞋楦往下压。最小化 Σ deficit² + λ·Σ 缩放偏离²。
- 这里用闭包**之前**的 φ_C(即 e(x) 的偏移)来计算;闭包带来的代价在 §2 里单独统计。
- M_below 只由模板自身决定(§1.5),和鞋楦位姿无关,所以这里是一次单纯的优化,不需要和鞋口曲线交替迭代。
- 约束:鞋楦脚掌最低点到打印床的距离 ≥ 最小底厚 s_min(默认 6 mm,参照 Zellerfeld 的鞋底约 8 mm,**决策点 D4**)。
- 求解:φ_E 用三线性插值查询,开销很小;先粗网格搜索再用 Nelder–Mead 细化。这一步替代 #7 中只做平移搜索的 `fit_to_last`。

### 1.5 外包络 φ_E

鞋口线是倾斜的:后跟处约 95–105 mm(§0 的实测),鞋舌口明显更低,估计约 65 mm,S2 实测后更新。所以不能逐个 z 层做二维孔洞填充:高于鞋舌口的切片是 U 形,不闭合,后跟上部的内腔不会被填上;同时"在哪一层断开"只能得到鞋口最低点的一个水平面。外包络和鞋口掩码都改为从**三维鞋口曲线**得到,而且**只用模板自身**,不依赖鞋楦位姿:

1. **区分内外表皮**:对每个面沿外法向,在一个小锥角(约 10°)内打 5 条射线,复用 audit `overhangs` 里的 first-hit 测试(`mesh.ray.intersects_location`)。多数射线再次打到模板的标为"内表皮",射出去的标为"外表皮"。之后只保留面积最大的那一块连通内表皮:外表皮上的外凹处(例如鞋面与凸出的鞋底边之间)可能被误标成内表皮,但它们面积小,也不和真正的内表皮相连。不再用"距鞋楦 ≤ 15 mm、法向朝向鞋楦"来判断:#7 测出的 6–8% 碰撞区里,内表皮在鞋楦内部,这个判断正好是反的。
2. **鞋口曲线**:内外表皮交界处最上方的那条闭合边界,即鞋口沿。对它做平滑和重采样,检查它是不是一条闭合环。
3. **封口**:把鞋口曲线插值成高度场 z_T(x, y)(在曲线围成的 xy 区域内做 Laplace 插值,区域外按最近曲线点外延),在鞋口处生成一张封口面。
4. **填充**:**外表皮(含鞋口沿)∪ 封口面**,去掉第 1 步标出的内表皮,再用广义绕数取内部,得到 φ_E。不能直接用"模板 ∪ 封口面":模板是闭合实体,旧内腔对它来说是外部,外表皮和内表皮的贡献正好抵消,内腔里的点绕数 ≈ 0;一张开放的封口面最多再贡献 0.5,所以内腔仍会被判成外部。已验算:开口杯子 + 封口面时,内腔三个点的绕数是 0.08–0.46。去掉内表皮之后,广义绕数正好用在它擅长的补洞场景,对小缝也不敏感。
5. **掩码**:M_below = {z < z_T(x, y)},§1.3 的位姿、§2 的补壁、§4.3 的截断都用这一个掩码。

S2 的测试:一个带倾斜鞋口的合成空心盒子鞋,断言旧内腔中心处 φ_E < 0、后跟上部(高于鞋口最低点)的旧内腔也 φ_E < 0。

镂空款:先做三维闭运算(半径 ≥ 最大镂空孔半径,先测量),再从闭运算结果的表面提取鞋口曲线,步骤同上。

风险:鞋口沿是圆滑过渡的,内外表皮的分界可能锯齿,也可能断成几段。兜底办法是人工在鞋口上标 8–12 个点,再拟合曲线;这一步做一次就可以按模板缓存下来。

镂空/格栅图案在 #10 里**不保留**:默认按实心外包络出图,图案交给 #13 的 SDF 细节层重新施加。也可以选择保留:φ_shoe 再与"原模板材料 ∪ 内衬层(内腔外 t_min 厚)"求交,鞋面保留原镂空、内侧有连续内衬。缺点是孔不再通透(**决策点 D2**)。

## 2. 壁厚不均、过薄、自相交

单个场经 marching cubes 提取,原始输出不会自相交(导出后的处理见 §1.1)。所以这里主要解决壁厚,按三级处理,每一级都有判据:

1. **全局:位姿与缩放**(§1.3)。消化掉系统性的偏差。
2. **局部光滑推移**(相当于对外表皮做受约束的非刚性形变,但在隐式场上完成)。**只处理合脚缺口**,也就是相对闭包前的 φ_C;闭包的代价单独由第 4 项处理。缺口要在**外表皮上**定义,不能定义成三维场:直接对一个只在薄窄带里非零的场做三维高斯卷积,窄带外的零值会把它稀释掉(3 mm 宽的带、σ = 8 mm 时,峰值只剩约 15%)。做法:
   - 在 φ_E 零等值面上(只取 M_below 内)采样点 q,need_fit(q) = max(0, t − φ_C(q))。
   - **贴床面**(z < 0.5 mm 且 nz < −0.9)固定 P = 0。否则靠近鞋底的侧壁缺口会扩散到鞋底面,沿 −z 把它推到打印床以下,鞋底不平,首层贴不住床。
   - 在表面点集上先做半径 R = 2σ 的**最大值滤波**,再做**归一化**高斯平滑:Σ w·v / Σ w,只对表面点求和,σ 约 6–10 mm。权重 w = G(|q_i − q_j|) · max(0, n_i·n_j):法向一致性项不让推移绕过尖锐的棱边扩散过去。高斯核在 R 处截断(scipy `truncate = 2`)。这样在缺口中心,参与平均的每个点都 ≥ need,所以 P ≥ need 严格成立;scipy 默认 truncate = 4 时只能做到约 0.97 × need。
   - 得到 P_fit(q),按最近点沿法向延拓到窄带,φ_1 = φ_E − P_fit(cp(x))。窄带半宽 ≥ max P_fit + 1 mm。P_fit 超过 4 mm 就已经判定模板不适用,所以 5 mm 的窄带就够了。
3. **硬补壁兜底**:φ_2 = min(φ_1, φ_C − t_fill),只在 M_below 内生效,t_fill = 1.5 mm(§1.4)。不补到 t_min = 1.2:补壁处的壁厚会正好等于审计阈值,加上 marching cubes 的误差,约一半的点会被测成 thin,frac_thin 就过不了。如果为了避免折痕要用平滑并集 smin,混合宽度 k ≤ 0.3 mm,必须小于 t − t_fill = 0.5 mm,否则正常壁厚的地方也会落进混合区。这一级是相对 φ_C 计算的,所以它的面积只反映合脚程度。
4. **闭包外壳**:φ_3 = min(φ_2, φ_A − t),给闭包新增的屋脊 A 包一层 t 厚的壳。屋脊最坏会伸出鞋头外包络约 30 mm,远超出第 2 级窄带的范围,用法向推移推不出去;如果交给第 3 级兜底,闭包的代价又会混进 Gate。所以单独处理,在导出后打上"闭包外壳"标签,不计入 Gate。

判据(写入报告,也作为 #9 Gate 的输入)。**Gate 只看反映模板是否合脚的指标**,而且看平滑**之前**的原始缺口 need_fit:平滑后的 P_fit 被最大值滤波向外扩了一圈 2σ。验算:σ = 8 mm 时,直径 10 mm 的缺口,P > 0.5 mm 的面积被放大约 14 倍,Gate 的结果会主要取决于 σ 这个可调参数。闭包代价归到 D3:回退路线(SDF 从零生成)一样要付这个代价,算进 Gate 就失去了判别力。

| 指标 | 可接受 | 判定模板不适用 | 是否进 Gate |
|---|---|---|---|
| need_fit p95 | ≤ 2 mm | 最大值 > 4 mm | 是 |
| need_fit > 0.5 mm 的外表皮面积 | ≤ 15% | > 30% | 是 |
| 第 3 级硬补壁面积(相对 φ_C) | ≤ 3% | > 10% | 是 |
| P_fit 的面积和最大值 | 只报告 | — | 否,衡量外形被改了多少 |
| 闭包外壳面积 / 屋脊最大伸出高度 | 只报告 | — | 否,用于 D3 |

"判定模板不适用"的含义:外形已经被改得不像原模板,模板路线对这一款不成立。回退顺序:先换模板(44 码或另一系列)重跑;所有模板都不适用时,#9 的 Gate 判失败,回到 **SDF 从零生成表皮**,即外表皮 = φ_C* − t(x) 再加造型偏移。本方案的 SDF 基础设施在回退路线里可以原样复用。

## 3. 悬垂:在构造时保证内腔自支撑

鞋底朝下打印时,内腔里朝下的面就是鞋面内侧的"天花板",也就是鞋头和鞋背的内侧。鞋楦脚尖附近的顶面接近水平(0.85 和 0.95 处顶高分别是 32.8 和 29.9),如果照原样做,就是一个约 60 mm 宽的水平悬空面。

**构造方法:对内腔做 45° 闭包。**从下往上逐层处理(层距 h = 体素尺寸):

```
V(z+h) = C(z+h) ∪ erode(V(z), h·tan α)      α = 45°(相对竖直方向)
```

意思是:内腔每升高 h,最多只能向内收 h·tan α,收得更快的部分会被补成空腔,形成"尖顶/穹顶"。

实现时有两个陷阱:

- 层内腐蚀**不能**直接拿三维 SDF 加常数。三维距离 ≤ 平面距离:在水平天花板正下方一层,三维距离就是 h,于是 φ_V + h·tan45° = 0,V 永远长不过天花板。
- 也**不能**用 `EDT2D > h·tan α` 这样的浮点比较。二值 EDT 只能取 1、√2、2 这些离散值,而 `tan(radians(45)) = 0.9999999999999999`,于是离边界 1 个体素的像素也满足 "> r",每层一个像素都不腐蚀,V 原样往上长到网格顶。已验算:α = 44° 和 45° 都长到网格顶;50° 和 55° 的结果完全一样,所以"放宽到 50°"在这种实现下也不起作用。

做法:**改变层距,而不是改变腐蚀半径**。每层只用 3×3 十字结构元做一次 `binary_erosion`(整数运算,没有浮点比较),通过层距控制角度:

```
dz = h / tan α_b        α_b = 43°(构造角,比审计的 45° 留 2° 余量,§1.4)
V_0 = C_0
V_{k+1} = C_{k+1} ∪ erode_cross(V_k)       在 z 方向重采样到 dz 的网格上逐层递推
```

沿坐标轴方向,每层正好收 1 个体素,斜率就是 α_b;沿对角方向,十字结构元每层只收约 0.71 个体素,比 α_b 更陡,也就更保守。算完之后按"任一子层为空腔即为空腔"的规则重采样回主网格。

只把闭包**新增**的部分二值化:A = V \ C,再向 C 里多膨胀 1 个体素,保证两者重叠、交界处不留薄膜。φ_A 只在 A 的包围盒里做内外两次三维 EDT,φ_C* = min(φ_C, φ_A)。这样鞋楦附近保持精确的 φ_C,误差只出现在屋脊上;如果把整个内腔都二值化,1 mm 体素下误差最大 0.47 mm,超出 §5.1 的间隙容差。这也省了内存:在 0.4 mm、91 M 体素的整个网格上做 EDT,峰值会到几 GB。

由于 V ⊇ C,闭包只会增加空腔,不会侵占鞋楦和松量的空间;天花板的每一点都有 ≤ α_b 的支撑。屋脊之外再由 §2 的"闭包外壳"包一层 t 厚的壳,壁厚不受影响。

S5 的测试:60 × 40 mm 的水平天花板,α_b ∈ {40°, 43°, 50°} 三种角度下,断言屋脊高度 ≈ 半宽 / tan α_b(误差 ±1 个体素),而不只是"长出了屋脊"。

需要注意的副作用和对应处理:

- **鞋头顶部被抬高**:闭包相当于在内腔天花板上加一个屋脊。60 mm 宽时,最坏情况下屋脊高约 30 mm,实际上鞋楦顶面本身是圆的,增加量会小得多。需要在最小可行实验(MVE)里实测增加了多少。如果抬得太高,可以选择:允许 TPU 跨距 b(例如 ≤ 8 mm)以内的短桥接,或者把 α_b 放宽到 50°(新实现下改层距即可)。这两个参数都要靠 #11 的打印实测来定(**决策点 D3**)。
- **后跟内收**:后跟在鞋口附近向内收,起包跟作用。闭包会把这部分削掉。如果后跟内收角度本身 ≤ α_b,闭包不会改动它;超出的部分在报告里单独列出"后跟包裹损失"。可以在后跟区域允许例外(内收部分很薄,TPU 可以桥接),也可以接受这部分损失(**决策点 D3**)。
- **外表皮的外悬垂**:外侧悬垂可以加外部支撑,事后能清掉,不属于 #10 要解决的问题,只要求补壁不让它变得更差(报告中对比 open_frac 的变化)。

**被否决的做法:**换打印朝向(侧放或倒放)。鞋底的质量和与打印床的附着都会变差,而且侧放时整个鞋面都会变成悬垂。双料可溶支撑:TPU 单喷头,而且内腔里的支撑仍然很难取出。

## 4. 松量与鞋口截断

### 4.1 松量建议(相对鞋楦表面的法向距离)

鞋楦本身已经包含了脚长余量(楦长大于脚长约 10–15 mm),所以这里的松量只用来抵消 TPU 打印误差和提供穿脱余量,不需要再按"脚到鞋"的松量来取。

| 区域 | 建议值 | 理由 |
|---|---|---|
| 鞋头(长度 0.85 以后) | +1.0 mm | 脚趾活动;顶部再由 45° 闭包额外增加 |
| 跖围两侧(0.60–0.85) | +0.5 mm | TPU 95A 有一定弹性,太松会滑脚 |
| 足弓与腰窝 | +0.5 mm | |
| 脚背(上表面 0.35–0.65) | +1.5 mm | 穿脱和系带空间;没有系带时需要更大 |
| 后跟(0–0.20) | +0.3 mm | 包跟,防止掉跟 |
| 地板(鞋楦底面) | +0.5 mm,另加鞋垫厚度 | 是否预留可拆鞋垫(3–4 mm)由**决策点 D1**决定 |
| FDM 收缩补偿 | 全局 +0.2 mm | 内孔打印出来通常偏小,数值待 #11 校准 |

分区定义在鞋楦的归一化坐标(长度比例、朝上/朝两侧/朝下的法向)上,区与区之间用 10 mm 宽的平滑过渡,得到连续的 e(x)。数值放在配置文件里,不写死在代码中。

### 4.2 壁厚目标

t = 2.0 mm(参考镂空款的中位数 2.6 mm);t_min = 1.2 mm 是审计阈值;硬补壁的构造值 t_fill = 1.5 mm(§1.4)。底部用 s_min 单独控制(§1.3)。

### 4.3 鞋口与鞋楦高出鞋口的部分

鞋楦高 136 mm,包括脚踝以上的楦柱;模板鞋口在后跟处约 95–105 mm。处理方法:

1. **鞋口线**:用 §1.5 从模板提取的三维鞋口曲线和高度场 z_T(x, y)。它是倾斜的:后跟约 95–105 mm,鞋舌口明显更低(估计约 65 mm,待 S2 实测)。后跟包跟(高于鞋舌口的那一段)因此落在 M_below 内,补壁会对它生效。#7 已经测到后跟有碰撞,如果这部分不在掩码内,新内腔会直接把包跟打穿。可选用 Zellerfeld 的 `ankle_height` 区域来校核高度(仅作内部参考)。
2. **内腔向上贯通**:按列处理。对每个 (x, y),找到 z_T(x, y) 以下最高的那个内腔点 z_c:**如果 z_T − z_c < t_fill**,就把这一列从 z_c 往上全部设为空腔。

   这条判据同时覆盖两种情况。一是鞋楦(加松量后)在 z_T 处本身是实的(z_c = z_T),这时内腔要从鞋口完整穿出,不能因为楦柱前倾或后倾而在鞋口留下一圈薄膜。二是开口内部:Laplace 插值出来的封口面可能略高于脚背,中间会夹着一片从约 3 mm 渐变到 0 的楔形薄盖。它比 t_min 还薄,而且上表面就是封口面,不在 M_below 内,补壁和倒圆都处理不到它。正常的壁(例如后跟包跟)在竖直方向上的厚度 ≥ t_fill,不会被这条规则削掉,但要在 MVE 的中线纵截面上确认。

   不用"某一个高度的截面统一向上挤出",因为鞋口是倾斜的:按鞋舌口高度的截面挤出,会把后跟那段包跟的内壁按鞋舌口处的轮廓削掉。
3. **补壁只在鞋口线以下生效**:鞋口线以上不推外表皮,避免把楦柱的形状"长"成鞋帮。
4. **鞋口圆角求交**:不用开运算,也不用"先加厚再开运算"。厚度为 T 的壁做半径 r 的开运算,腐蚀后剩下的核心宽度是 T − 2r;r = T/2 时核心宽度为 0,体素网格表示不出来,重算距离后什么都不剩(评审验算:T = 3、r = 1.5、0.4 mm 体素下,5 种网格偏移全部被删掉)。改为把壁的场 φ_W 和鞋口面 z − z_T 做**圆角求交**(round intersection,即 hg_sdf 的 `fOpIntersectionRound`):

   ```
   roundI(a, b, r) = min(−r, max(a, b)) + ‖(max(r + a, 0), max(r + b, 0))‖
   ```

   它直接在内外两条凸边上生成半径 r 的圆角,不需要腐蚀,也不需要重算距离。r = 1.0 mm。T = 2r 时得到半圆形的整圆角,不会消失;T < 2r 时只会让鞋口顶边略微降低,也不会消失。z − z_T 只是鞋口面的近似距离:鞋口坡度约 0.25,误差约 3%,对 1 mm 的圆角可以忽略。这一步同时把鞋口线以上的部分整齐地切掉。§5.1 的壁厚指标对鞋口不单独放宽。

### 5.2 最小可行实验(MVE)

1. 输入:`dlp_solid_43_right`(没有镂空,外包络最好得到)和 `sneaker_last`;体素 1.0 mm,统一松量 1.0 mm,t = 2.0 mm。

3. 再换 `dlp_hollow_43_right` 跑一遍,外包络用闭运算得到。
4. 输出:STL、报告 JSON,以及截面图:长度 0.05 / 0.30 / 0.70 / 0.95 处的横截面,再加一张**沿中线的纵截面**(xz 平面)。鞋舌口、鞋头屋脊、后跟包跟和楔形薄盖都在这张纵截面上,比只看横截面更容易发现问题。

| 做法 | 否决理由 |
|---|---|
| 复用并形变模板自带的内腔 | #7 已测得:最佳低位仍有 6–8% 表面碰撞,脚跟、鞋头、一侧和内底坡度同时没有松量;原内腔精度 ±2–4 mm,不够用 |
