## 1. 几何做法

### 1.1 表示:在规则网格的带符号距离场(SDF)上做

所有体素运算都在一个共享的规则体素网格上完成(φ < 0 表示在内部):

- 体素:迭代时用 1.0 mm,出图用 0.4 mm(≤ 最小壁厚 1.2 mm 的 1/3,保证 marching cubes 的误差不会吞掉壁厚)。网格范围约 300 × 130 × 150 mm:1.0 mm 时约 5.9 M 个体素(float32 约 23 MB);0.4 mm 时约 91 M 个(约 370 MB,中间场再乘几倍)。因此出图时分块计算,或只在窄带内保存精确距离、窄带外只存符号。
- 网格转 SDF:距离用最近三角形(`libigl` 的 AABB 树),符号用**快速广义绕数**(fast winding number)。它对 100 万面的镂空网格、局部不水密的网格都稳定。
- SDF 转网格:用 `skimage.measure.marching_cubes`,网格四周留 2 个体素的空边。这样的**原始输出**是水密、无自相交的。之后的处理:
  - 只保留最大连通分量,并在报告里记录丢掉的碎块体积。碎块体积 > 1 cm³ 视为构造错误,直接判失败,不悄悄丢掉。
  - 出图版本默认**不做简化**(0.4 mm 体素下约 2–4 M 面,切片软件可以处理)。确实需要简化时,简化后必须重跑完整 audit(水密、自相交、壁厚),并且简化误差 ≤ 0.1 mm。
  - 这里只保证"marching cubes 原始输出天然水密",之后每一步都靠 audit 复核,不再声称"天然成立"。
- 新增依赖:`libigl`、`scikit-image`(**决策点 D6**)。

选 SDF 的理由:和路线图(SDF 细节层,#13)用同一种表示;offset 就是对 φ 加常数,布尔运算就是取 min/max,天然不会自相交;壁厚、自支撑这类约束能写成对场的逐点运算,在构造时就成立。

### 1.2 几个场

| 符号 | 含义 | 怎么得到 |
|---|---|---|
| φ_L | 鞋楦 | 鞋楦网格转 SDF,并施加 §1.3 求出的位姿 |
| φ_E | 模板**外包络**(封住内腔和镂空后的实心外形) | §1.4 |
| e(x) | 松量场(按区平滑变化) | §4 |
| t(x) | 目标壁厚场 | 默认 2.0 mm,下限 1.2 mm |
| z_T(x, y) | 鞋口高度场(三维鞋口曲线插值成的曲面),给出"鞋口线以下"掩码 M_below | §1.4、§4.3 |

内腔:φ_C = φ_L − e(x),再并上鞋口上方的竖直挤出(§4.3),然后做自支撑闭包(§3),得到 φ_C*。

鞋体:

```
φ_E'  = 补壁后的外包络(§2)   保证 φ_E' ≤ φ_C* − t 在鞋口线以下处处成立
φ_shoe = max(φ_E', −φ_C*)       外包络减去内腔
```

### 1.3 鞋楦在模板里的位姿

鞋楦的形状不能改;能改的是鞋楦相对模板的刚体位姿,以及模板外包络的整体缩放(属于造型,允许)。

- 变量:dx, dy, dz, 俯仰角 pitch, 偏航角 yaw(±3°);可选模板各向异性缩放 sx, sy ∈ [0.97, 1.05]。
- 目标:在鞋楦表面采样点 p 上,定义缺口 deficit(p) = max(0, φ_E(p) + e(p) + t(p))(外表皮离鞋楦不够远的量)。**只对 M_below 内的采样点求和**:鞋口以上的楦柱 deficit 有几十 mm,算进去会让优化器只顾把鞋楦往下压。最小化 Σ deficit² + λ·Σ 缩放偏离²。
- 这里用闭包**之前**的 φ_C(即 e(x) 的偏移)来计算;闭包带来的代价在 §2 里单独统计。
- M_below 依赖鞋口曲线,而鞋口曲线的提取(§1.4)又需要一个大致的位姿。做法:先用 #7 的平移搜索结果作为初始位姿提取鞋口曲线,再优化位姿;如果位姿变化 > 3 mm,就重新提取一次鞋口曲线(最多 2 轮)。
- 约束:鞋楦脚掌最低点到打印床的距离 ≥ 最小底厚 s_min(默认 6 mm,参照 Zellerfeld 的鞋底约 8 mm,**决策点 D4**)。
- 求解:φ_E 用三线性插值查询,开销很小;先粗网格搜索再用 Nelder–Mead 细化。这一步替代 #7 中只做平移搜索的 `fit_to_last`。

### 1.4 外包络 φ_E

鞋口线是倾斜的:鞋舌口约 65 mm,后跟约 100 mm。所以不能逐个 z 层做二维孔洞填充:高于鞋舌口的切片是 U 形,不闭合,后跟上部的内腔不会被填上;同时"在哪一层断开"只能得到鞋口最低点的一个水平面。外包络和鞋口掩码都改为从**三维鞋口曲线**得到:

1. **区分内外表皮**:取初始位姿下的鞋楦,把模板上距鞋楦 ≤ 15 mm、法向朝向鞋楦的面标为"内表皮",其余为"外表皮"。
2. **鞋口曲线**:内外表皮交界处最上方的那条闭合边界,即鞋口沿。对它做平滑和重采样,检查它是不是一条闭合环。
3. **封口**:把鞋口曲线插值成高度场 z_T(x, y)(在曲线围成的 xy 区域内做 Laplace 插值,区域外按最近曲线点外延),在鞋口处生成一张封口面。
4. **填充**:模板 ∪ 封口面,用广义绕数取内部,得到 φ_E。广义绕数对封口面和模板之间的小缝不敏感。
5. **掩码**:M_below = {z < z_T(x, y)},§1.3 的位姿、§2 的补壁、§4.3 的截断都用这一个掩码。

镂空款:先做三维闭运算(半径 ≥ 最大镂空孔半径,先测量),再从闭运算结果的表面提取鞋口曲线,步骤同上。

风险:鞋口沿是圆滑过渡的,内外表皮的分界可能锯齿,也可能断成几段。兜底办法是人工在鞋口上标 8–12 个点,再拟合曲线;这一步做一次就可以按模板缓存下来。
- 镂空/格栅图案在 #10 里**不保留**:默认按实心外包络出图,图案交给 #13 的 SDF 细节层重新施加。也可以选择保留:φ_shoe 再与"原模板材料 ∪ 内衬层(内腔外 t_min 厚)"求交,鞋面保留原镂空、内侧有连续内衬。缺点是孔不再通透(**决策点 D2**)。

## 2. 壁厚不均、过薄、自相交

单个场经 marching cubes 提取,原始输出不会自相交(导出后的处理见 §1.1)。所以这里主要解决壁厚,按三级处理,每一级都有判据:

1. **全局:位姿与缩放**(§1.3)。消化掉系统性的偏差。
2. **局部光滑推移**(相当于对外表皮做受约束的非刚性形变,但在隐式场上完成)。缺口要在**外表皮上**定义,不能定义成三维场:如果直接对一个只在薄窄带里非零的场做三维高斯卷积,窄带外的零值会把它稀释掉。以 3 mm 宽的带、σ = 8 mm 为例,峰值只剩约 15%。做法:
   - 在 φ_E 零等值面上(只取 M_below 内)采样点 q,需求推移量 need(q) = max(0, t − φ_C*(q))。φ_C*(q) 就是 q 到内腔的距离,也就是该处的壁厚。
   - 在表面点集上先做半径 r = 2σ 的**最大值滤波**,再做**归一化**高斯平滑:Σ w·v / Σ w,只对表面点求和,σ 约 6–10 mm。最大值滤波保证缺口中心的推移量不小于 need,归一化保证不被窄带外的零值稀释。
   - 得到表面推移场 P(q),按最近点沿法向延拓到窄带,φ_E' = φ_E − P(cp(x))。
   - **两种推移分开算**:P_fit 相对闭包前的 φ_C 计算,反映模板合不合脚;P_total 相对闭包后的 φ_C* 计算。二者之差 P_closure = P_total − P_fit 是悬垂规则的代价(§3)。实际施加的是 P_total。
3. **硬补壁兜底**:φ_E'' = min(φ_E', φ_C* − t_min),只在 M_below 内生效。为了避免折痕,可以用平滑并集 smin,但混合宽度 k ≤ 0.3 mm。k 必须小于 t − t_min = 0.8 mm,否则正常 2 mm 壁厚的地方也会落进混合区(k = 2 mm 时,2.0 mm 壁厚处外表皮会外移约 0.18 mm,"补壁面积"会被统计成接近 100%)。补壁面积按导出后的标签统计(§5.1):只算 φ_C* − t_min 这一项起作用的面。

判据(写入报告,也作为 #9 Gate 的输入)。**Gate 只看反映模板是否合脚的指标**,闭包代价归到 D3。理由:回退路线(SDF 从零生成)一样要付闭包代价,把它算进 Gate 就失去了判别力。

| 指标 | 可接受 | 判定模板不适用 | 是否进 Gate |
|---|---|---|---|
| P_fit p95 | ≤ 2 mm | 最大值 > 4 mm | 是 |
| P_fit > 0.5 mm 的外表皮面积 | ≤ 15% | > 30% | 是 |
| 第 3 级硬补壁面积 | ≤ 3% | > 10% | 是 |
| P_closure 最大值 / 面积 | 只报告 | — | 否,用于 D3 |

"判定模板不适用"的含义:外形已经被改得不像原模板,模板路线对这一款不成立。回退顺序:先换模板(44 码或另一系列)重跑;所有模板都不适用时,#9 的 Gate 判失败,回到 **SDF 从零生成表皮**,即外表皮 = φ_C* − t(x) 再加造型偏移。本方案的 SDF 基础设施在回退路线里可以原样复用。

## 3. 悬垂:在构造时保证内腔自支撑

鞋底朝下打印时,内腔里朝下的面就是鞋面内侧的"天花板",也就是鞋头和鞋背的内侧。鞋楦脚尖附近的顶面接近水平(0.85 和 0.95 处顶高分别是 32.8 和 29.9),如果照原样做,就是一个约 60 mm 宽的水平悬空面。

**构造方法:对内腔做 45° 闭包。**从下往上逐层处理(层距 h = 体素尺寸):

```
V(z+h) = C(z+h) ∪ erode(V(z), h·tan α)      α = 45°(相对竖直方向)
```

意思是:内腔每升高 h,最多只能向内收 h·tan α,收得更快的部分会被补成空腔,形成"尖顶/穹顶"。

实现时,层内腐蚀**必须用二维平面距离**,不能直接拿三维 SDF 加常数。三维距离 ≤ 平面距离:在水平天花板正下方一层,三维距离就是 h,于是 φ_V + h·tan45° = 0,V 永远长不过天花板,要解决的 60 mm 水平悬空面会原样保留。正确做法是在二值掩码上逐层递推:

```
V_0 = C_0
V_{k+1} = C_{k+1} ∪ { p : EDT2D(V_k)(p) > h·tan α }     EDT2D = 本层切片内到空腔边界的二维欧氏距离
```

EDT2D 用 `scipy.ndimage.distance_transform_edt`,按体素尺寸设置 sampling。全部层算完之后,再把 V 统一转回三维 SDF,得到 φ_C*:对掩码的内外两侧各做一次三维 EDT,带亚体素误差(≤ 体素尺寸的一半),写进 §5.1 的容差。由于 V ⊇ C,闭包只会增加空腔,不会侵占鞋楦和松量的空间;天花板的每一点都有 ≤ 45° 的支撑。之后第 2 节的壁厚处理是相对 φ_C* 计算的,所以闭包把天花板抬高后,外表皮也会相应被推开,壁厚不受影响。

需要注意的副作用和对应处理:

- **鞋头顶部被抬高**:闭包相当于在内腔天花板上加一个屋脊。60 mm 宽时,最坏情况下屋脊高约 30 mm,实际上鞋楦顶面本身是圆的,增加量会小得多。需要在最小可行实验(MVE)里实测增加了多少。如果抬得太高,可以选择:允许 TPU 跨距 b(例如 ≤ 8 mm)以内的短桥接,或者把 α 放宽到 50°。这两个参数都要靠 #11 的打印实测来定(**决策点 D3**)。
- **后跟内收**:后跟在鞋口附近向内收,起包跟作用。闭包会把这部分削掉。如果后跟内收角度本身 ≤ 45°,闭包不会改动它;超出的部分在报告里单独列出"后跟包裹损失"。可以在后跟区域允许例外(内收部分很薄,TPU 可以桥接),也可以接受这部分损失(**决策点 D3**)。
- **外表皮的外悬垂**:外侧悬垂可以加外部支撑,事后能清掉,不属于 #10 要解决的问题,只要求补壁不让它变得更差(报告中对比 open_frac 的变化)。

**被否决的做法:**换打印朝向(侧放或倒放)。鞋底的质量和与打印床的附着都会变差,而且侧放时整个鞋面都会变成悬垂。双料可溶支撑:TPU 单喷头,而且内腔里的支撑仍然很难取出。

## 4. 松量与鞋口截断

### 4.1 松量建议(相对鞋楦表面的法向距离)

鞋楦本身已经包含了脚长余量(楦长大于脚长约 10–15 mm),所以这里的松量只用来抵消 TPU 打印误差和提供穿脱余量,不需要再按"脚到鞋"的松量来取。

| 区域 | 建议值 | 理由 |
|---|---|---|
| 鞋头(长度 0.85 以后) | +1.0 mm | 脚趾活动;顶部再由 45° 闭包额外增加 |
| 跖围两侧(0.60–0.85) | +0.5 mm | TPU 95A 有一定弹性,太松会滑脚 |
| 足弓与腰窝 | +0.5 mm | |
| 脚背(上表面 0.35–0.65) | +1.5 mm | 穿脱和系带空间;没有系带时需要更大 |
| 后跟(0–0.20) | +0.3 mm | 包跟,防止掉跟 |
| 地板(鞋楦底面) | +0.5 mm,另加鞋垫厚度 | 是否预留可拆鞋垫(3–4 mm)由**决策点 D1**决定 |
| FDM 收缩补偿 | 全局 +0.2 mm | 内孔打印出来通常偏小,数值待 #11 校准 |

分区定义在鞋楦的归一化坐标(长度比例、朝上/朝两侧/朝下的法向)上,区与区之间用 10 mm 宽的平滑过渡,得到连续的 e(x)。数值放在配置文件里,不写死在代码中。

### 4.2 壁厚目标

t = 2.0 mm(参考镂空款的中位数 2.6 mm);t_min = 1.2 mm(和审计阈值一致)。底部用 s_min 单独控制(§1.3)。

### 4.3 鞋口与鞋楦高出鞋口的部分

鞋楦高 136 mm,包括脚踝以上的楦柱;模板鞋口在后跟处约 95–105 mm。处理方法:

1. **鞋口线**:用 §1.4 从模板提取的三维鞋口曲线和高度场 z_T(x, y)。它是倾斜的:鞋舌口约 65 mm,后跟约 100 mm。后跟包跟(z 在 65–100 之间)因此落在 M_below 内,补壁会对它生效。#7 已经测到后跟有碰撞,如果这部分不在掩码内,新内腔会直接把包跟打穿。可选用 Zellerfeld 的 `ankle_height` 区域来校核高度(仅作内部参考)。
2. **内腔向上贯通**:按列处理。对每个 (x, y),如果鞋楦(加松量后)在本地鞋口高度 z_T(x, y) 处是实的,就把这一列 z ≥ z_T(x, y) 的部分全部设为空腔,再与鞋楦求并集。这样内腔会从鞋口完整穿出,不会因为楦柱前倾或后倾而在鞋口留下一圈薄膜。不用"某一个高度的截面统一向上挤出",因为鞋口是倾斜的:按鞋舌口 65 mm 的截面挤出,会把后跟 65–100 mm 那段包跟的内壁按 65 mm 处的轮廓削掉。
3. **补壁只在鞋口线以下生效**:鞋口线以上不推外表皮,避免把楦柱的形状"长"成鞋帮。
4. **鞋口加厚再倒圆**:不能对整只鞋做"先 offset 再反向 offset"。开运算会删掉所有厚度 < 2r 的特征,r = 1.5 mm 时 2 mm 的壁会整片消失;闭运算只处理凹角,凸的鞋口边不会变圆。另外,倒圆只会让边缘变薄,不会变厚。做法:
   - 只在鞋口曲线附近的窄带内(距 z_T ≤ 8 mm)操作;
   - 先把鞋口沿局部加厚到 t_rim = 3 mm(和 §2 第 2 级同一套机制,只是目标壁厚换成 t_rim);
   - 再做半径 r ≤ t_rim / 2 = 1.5 mm 的局部倒圆(在窄带内取 SDF 的开运算,窄带外保持原值,交界处做混合)。
   - 加厚和倒圆之后,鞋口一带的壁厚仍然要满足 ≥ t_min,§5.1 的壁厚指标对鞋口不再单独放宽。

## 5. 验证

### 5.1 复用和扩展 `shoe-assets audit`

| 指标 | 来源 | 通过标准 |
|---|---|---|
| 水密、单体 | `geometry` | watertight = True,bodies = 1;导出时丢弃的碎块 ≤ 1 cm³(§1.1) |
| 壁厚 | `wall_thickness` | frac_thin(< 1.2 mm)≤ 0.5%,p5 ≥ 1.5 mm。设计上处处 ≥ t_min,0.5% 是给采样射线斜穿圆角边缘造成的测量误差留的余量 |
| 内腔悬垂 | `overhangs`,新增按面来源标注 | 内腔面中 > 45° 的面积 ≈ 0(≤ 0.2%,仅限 ≤ b 的桥接) |
| 外悬垂 | `overhangs.open_frac` | 不高于原模板 |
| 带符号间隙 | `fit_to_last`,新增"固定位姿"模式 | 碰撞 = 0;间隙 ≥ e(x) − 0.3 mm(体素误差);分区间隙中位数与设定松量相差 ≤ 0.3 mm |
| 补壁 | 新增 | 满足 §2 的判据表 |
| 打印尺寸 | 新增 | 能放进打印机成型空间,可以斜放(**决策点 D5**:281 mm 长放不进 256 mm 的打印床,斜放对角线约 362 mm) |

需要对审计做的两处扩展,都很小:

- `fit_to_last` 增加"给定位姿"模式:新鞋的位姿由构造时确定,不需要再搜索。
- **导出后给每个面打来源标签**:marching cubes 输出的是新面片,和 min/max 里哪一支起作用之间没有对应关系,所以"构造时记录"做不到。改为在每个面的质心处分别采样 −φ_C*、φ_E'、φ_C* − t_min 三个场,取 |值| 最小的那一个作为标签(内腔 / 外表皮 / 补壁);如果两个场的 |值| 都 < 0.5 个体素,标为"混合"。据此把悬垂、壁厚和补壁面积按来源分开统计。这一步只依赖导出的网格和保存下来的场,所以 S7 不依赖 S6 的内部状态。现在 audit 中"enclosed"的定义是"下方有材料",区分不出内腔天花板,这个标签正好补上。

### 5.2 最小可行实验(MVE)

1. 输入:`dlp_solid_43_right`(没有镂空,外包络最好得到)和 `sneaker_last`;体素 1.0 mm,统一松量 1.0 mm,t = 2.0 mm。
2. 跑两组:不做 45° 闭包、做 45° 闭包,对比天花板增加的高度、外表皮被推移的量和各项指标。
3. 再换 `dlp_hollow_43_right` 跑一遍,外包络用闭运算得到。
4. 输出:STL、报告 JSON,以及截面图(长度 0.05 / 0.30 / 0.70 / 0.95 处)。
5. 打印验证(交给 #11,但 MVE 先准备好文件):只切出鞋头前 1/3 打印,验证天花板闭包和桥接,比打整只鞋快得多,也省料。

预计 MVE 需要 2–3 天(大部分时间在 SDF 基础设施和分块计算的性能上)。

## 7. 被否决的备选做法

| 做法 | 否决理由 |
|---|---|
| 复用并形变模板自带的内腔 | #7 已测得:最佳低位仍有 6–8% 表面碰撞,脚跟、鞋头、一侧和内底坡度同时没有松量;原内腔精度 ±2–4 mm,不够用 |
| 鞋楦网格沿顶点法向外扩得到内腔 | 凹处(足弓、脚踝)外扩后会自相交,外扩距离也不均匀 |
| 网格布尔运算(`manifold3d`:模板 − 外扩鞋楦) | 布尔本身稳健,但外扩、壁厚保证、自支撑都要另外实现;镂空款 100 万面,运算很重。保留作为 SDF 结果的交叉校验工具 |
| 对整只模板做 cage/ARAP 非刚性形变去贴合鞋楦 | 会把不可用的旧内腔一起带着变形;有自相交风险,需要额外检测;参数多且难调。§2 的"隐式场推移"已经做到了同样的效果 |
| 事后检查悬垂再打补丁 | 补丁位置不可控,可能在内腔里产生清不掉的支撑。改为在构造阶段用闭包保证 |
| 神经隐式场 / 学习方法 | v1 单码、单模板,用不上;没有训练数据 |
| 换打印朝向 / 可溶支撑 | 见 §3 |

## 8. 需要用户拍板的决策点

- **D1 松量与鞋垫**:§4.1 的分区数值是否接受;要不要预留 3–4 mm 的可拆鞋垫空间;成鞋是否有系带(影响脚背松量)。
- **D2 镂空**:#10 是只出实心外包络(推荐,图案交给 #13),还是保留原镂空并加内衬。
- **D3 悬垂规则**:内腔严格 45°,还是允许 ≤ b mm 的短桥接或放宽到 50°;后跟包裹是否允许例外。建议先按 45° 做,等 #11 实测后再放宽。
- **D4 厚度**:壁厚目标 2.0 / 下限 1.2 mm,鞋底最小厚度 6 mm,是否接受。
- **D5 打印机**:型号和成型空间。281 mm 长需要斜放,或者需要更大的打印机。
- **D6 新依赖**:是否接受引入 `libigl` 和 `scikit-image`。
- **D7 MVE 模板**:先用实心 43 码(推荐),再用镂空 43 码。
- **D8 Gate 阈值**:§2 判据表里"判定模板不适用"的数值(只针对 P_fit 和硬补壁,不含闭包代价),直接决定 #9 是否回退到 SDF 从零生成。
- **D9 Zellerfeld 区域文件**:是否允许用 `ankle_height` 和 `sole_thickness_region` 作内部参考(CC BY-NC-ND,产物不能分发)。
