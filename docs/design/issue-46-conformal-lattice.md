## 1. 随形坐标系

要解决的问题:#14 的 Voronoi/蜂巢在图 `(r0·θ, x)` 里算,边是该图里的直线,图与鞋面形状无关;脚尖、脚跟端截面→0 时纱线收束成漩涡。

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A 解析图(原型已做)** | `p` = 截面轮廓弧长(周期 C = n·pitch),`t` = ∫ r0·m(x)/ρ(x) dx(ρ = 轮廓周长/2π,m = 子午方向拉伸)。圆柱对称时 (θ, ∫dx/ρ) 严格保角 | 零网格、闭式、整圈周期无接缝、O(1)/体素;参数少 | 鞋面不是旋成面,实测各向异性中位 1.35;两端是极点,不能直接铺 |
| **B LSCM(libigl 已是依赖)** | 鞋面中面网格(开口处裁开)→ 最小二乘保角展平,体素到 (u,v) 用最近三角形重心插值 | 保角,各向异性 ≈ 1.00(探针,见 §5);脚尖/鞋口区可用 | 需要网格+最近点查询;面积畸变要报告;整鞋是环带 + 两端帽,要切缝;旧设计(ADR 0005)的结论:接缝放后跟中线用实体条盖住 |
| C 测地距离 + 角度(heat method 等) | 以鞋口线/鞋底边为参考的 (τ, s) | 与"鞋口到鞋底边"的流线语义吻合 | 依赖场的稳定性,实现最重,没有现成依赖 |

**选择(待你确认)**:鞋筒(鞋面主体)用 B(LSCM)——原型数据说明解析图 A 对"随形"几乎没有改善(各向异性 1.35 → 1.37,与 #14 的 1.35 相同),
真正保角要靠 LSCM;A 作为极点以外的快速路径和回退。脚尖帽、脚跟帽不展平,做成"收口环 + 少量放射杆"的极点处理(旧设计也是这样:两端留实体/收束环)。
**扭曲预算**:取各向异性 s1/s2 的 p95 ≤ 1.25、面积比 p05/p95 在 [0.7, 1.4],超出则缩小该片区或改用极点处理;构建时报告最大值,不过线就拒绝(与 #16 的 clamp 报告同一机制)。
**接缝**:放后跟中线,用 8–10 mm 宽的实体条盖住(后跟补强片本来就是实体);A 的周期坐标没有接缝,LSCM 才需要。

## 2. 流场

在图 `(p, t)` 上定义纱线方向 `α(p, t)`(与脚长轴夹角):`α = sweep(u) + amp(u)·cos(θ − θ0)`(沿脚长的平均斜率 + 绕脚的一次谐波,都是配置)。
从基线 `t = t0` 用 RK2 积分流线,得到流线标号 ψ 和沿流线弧长 φ,存成 (t, p) 网格上的表(周期,0.5 mm)。
**流线收束检查**:ψ 对 p 的导数(相邻流线间距比)必须在 `flow_compress`(默认 [0.55, 1.8])内,否则拒绝(演示里 30° 谐波会得到 [0.06, 16],被正确拒绝)。
晶格单元 = 抖动六角种子的 Voronoi,种子放在**真实几何的正交化流坐标** `(S/elongate, N)`,`S = φ + ψ sin a`、`N = ψ cos a`(a 为基线斜率),
所以细胞沿流线拉长而不是被剪成平行四边形(第一版没做这步,各向异性 1.8;做了以后回到 1.35)。备选:曲率流场(沿主曲率方向)、
用户手绘/图片给方向场(#16 接口),都只需要换 `alpha()`,不用改后面。风险:流场和鞋带/鞋舌的相对位置还没定义(没有鞋带孔)。

## 3. 杆沿流线弯曲且保证杆径

杆 = Voronoi 胞元边界。边界距离在 (φ, ψ) 空间算(含圆角软最小),梯度经 `(φ,ψ) → (p,t) → 世界` 链式换算,再用 #14 已有的**精确世界坐标圆管公式**
`d² = (a² + b² − 2ab·c)/(1 − c²)`(a = 到中面有符号距离,b = 距离/梯度模,c = 两面法向夹角余弦):
杆是世界里的圆截面管,直径只取决于配置,与图的畸变无关(畸变只影响胞元形状/大小)。`1 − c²` 下限沿用 `MIN_SIN2`(杆几乎贴面走的地方变成带状,不会变细)。
**实测杆径用二值体素独立测量**(不用生成它的场):实体骨架(`skimage.skeletonize`)上取 `2·max3×3×3 EDT·h`;在直管上标定(2.4/3.5/5.5 mm、三个朝向,体素 0.5 mm):
误差 −0.16/−0.04/−0.11 mm,**远小于 1 个体素(0.5 mm)**,测试 `test_rod_measurement_within_one_voxel` 固定了这一点。

## 4. 一体化鞋底(检查点 2 的设想,需你拍板)

取消 `sole_mode = "slab"` 的方格 BCC 平台;鞋底由三部分组成,与鞋面同一图案家族(同一个 `style`/`pitch`/`fillet`/杆径族):
1. **外沿环**:沿鞋底外形(内腔足印向外偏移 + 侧壁外扩)的一条实心圆管环 + 第二条内环,直径 = 鞋面主杆径 × 1.3–1.5,做鞋底侧壁(厚而弧形的轮廓由 §5 的函数给)。
2. **脚下支撑网**:同风格 Voronoi/三角网,铺在足印曲面上(用 LSCM 展平足印,或直接在 (x, y) 上算,因为鞋底近似平面,**这里欧氏就够**,旧设计 ADR 0005 也是这个结论),
   杆更粗(支撑)、孔更小(< 12 mm),密度分区沿用 #14 的 `density = [(u, 体积占比)]`(前掌疏、脚跟密)。
3. **支撑面/脚垫**:内腔下 `pad_layer` 保留 #14 的 2 mm 实心薄皮(`skin_cavity_mm`)或脚垫层加粗杆(二选一,**问你**:实心薄皮对舒适/清粉更保守,加粗杆更像概念图但脚底有网格压痕)。
开放出粉通道:鞋底下表面不封(`sole_skin_outsole_mm = 0`),足印内侧全开口;封闭空腔 0 由检查保证。
备选:(a) 整个鞋底是一个 gyroid/BCC 厚块(#14 已做,与鞋面家族脱节,不选);(b) 概念图款式 3 的少量大环(脚下没有支撑面,不选)。
**未知**:缓震靠杆的弯曲,TPU 杆径 2.4–3.5 mm、孔 12 mm 的压缩行为没有数据,以 #11 试件和实物为准。

## 5. 轮廓函数库(接口草案,检查点 2 实现)

`outline.py`:`T(x, y, z) = T0 + Σ f_i(x, y, z; params_i)`,每个函数是**只增厚**的有界窗口(`f ≥ 0`,值域上限 `dT_max`),内腔不动(`phi_C < 0` 处不取值)。
```
@dataclass(frozen=True) class Bump:  name, dT_mm (default, [lo, hi]), u_range, z_range (相对内腔底), normal ∈ {all, side, top, front, back}, ramp_u, ramp_z
SHAPES = {toe_round, toe_square, toe_spring, toe_box_high, heel_counter, sole_wall(rounded), forefoot_cradle, collar_tuck, collar_roll, pull_tab}
def compose(shapes, prep) -> T3  (3D 粗场)    # 求和后 clip 到 [T0, T_max]; 构建前 check_outline() 越界即拒绝
```
每个函数带 `range`(例如 `toe_box_high.dT ∈ [0, 20] mm`,默认 8)和 `default`。**不侵入内腔**用两层保证:`T ≥ 0` + 构建前断言 `min(phi_C) ≥ 0` 在壳内,测试覆盖。
鞋口收口/卷边是 `collar_tuck`(沿 u 的内倾量,受鞋楦顶限制)+ `collar_roll`(圆截面卷边,直径 ≥ 杆径 × 1.3);拉环 `pull_tab` 是扁带(宽 14–20 mm,厚 ≥ 2.4 mm)。
`lattice_variants.thickness_field` 里的 `bumps`、`rim_thick`、`heel_counter`、`toe_cap` 已是这些函数的雏形,检查点 2 把它们抽成库并增加厚底侧壁、摇篮、卷边、扁拉环(不改 #14 现有行为)。

## 7. 原型结果(前掌一小块鞋面:u ∈ [0.45, 0.75],`dlp_solid_44_right` + `sneaker_last` 的内腔)

补丁 83×103×78 mm,体素 0.5 mm(杆 2.4 mm → ≤ 0.6 mm,可印判定通过),杆 2.4 mm、胞元 17 mm,壳厚 3.4 mm。四个变体,同一补丁同一杆径:

| | c0 #14 直边 | c1 随形图(无流场) | c2 随形+流场 | c3 强流场(胞元 14 mm、拉长 2.4×) |
|---|---|---|---|---|
| 杆径实测中位 / p05(设定 2.4,测量偏差 −0.16) | 2.24 / 2.00 | 2.24 / 2.00 | 2.24 / 2.00 | 2.24 / 2.00 |
| 骨架体素 < 设定 − 1 体素 | 2.8 % | 2.5 % | 2.7 % | 3.9 % |
| 胞元各向异性 s1/s2 中位 / p95 / 最大 | 1.35 / 1.75 / 1.94 | 1.37 / 2.03 / 2.31 | 1.35 / 2.02 / 2.17 | 1.43 / 1.85 / 2.00 |
| 胞元面积比 p05 / p95(对中位) | 0.82 / 1.17 | 0.94 / 1.09 | 0.89 / 1.13 | 0.87 / 1.20 |
| 流线间距比 dψ/dp | - | 1.0 | 0.64–1.56 | 0.53–1.96 |
| 窗(镂空)内切球直径中位 / p05 / p95 mm;< 5 mm 的窗 | 5.4 / 2.0 / 17.5;26 / 56 | 7.3 / 1.9 / 16.7;17 / 47 | 5.5 / 1.2 / 15.7;18 / 51 | 6.6 / 1.5 / 10.4;12 / 46 |
| 耗时 / 峰值内存 | 2.9 s / 1.45 GB | 3.6 s / 1.50 GB | 4.7 s / 1.52 GB | 3.7 s / 1.52 GB |

读数:
* **杆径**:四个变体一致,中位恒为 2.24(= 标定后的 2.4),p05 = 2.0,**偏差 ≤ 0.4 mm < 1 体素(0.5 mm)**;约 2.5–4% 的骨架体素更细(宽 2–3.5 体素,散在各处,与基线 #14 同量级),
  是骨架毛刺还是真的细颈,骨架法分不开;检查点 2 改用网格/分支长度加权复测,并把"最细处"做成硬检查。
* **展平扭曲(重要的负面结果)**:解析图 A 并没有降低各向异性(1.35→1.37);流场不增加扭曲(1.35),说明"正交化流坐标"这一步有效,瓶颈是 `(p, t)` 本身(鞋面不是旋成面,前掌顶面坡度大、截面接近扁椭圆)。
  **LSCM 探针**(`lattice_lscm_probe.py`,同一补丁中面):各向异性 1.00(保角,p95 1.003),面积比 p05/p95 = 0.96/1.05,耗时 0.6 s——**但探针网格不干净**(marching cubes 有 1090 个面积 < 0.01 mm² 的碎三角,
  焊接后拓扑不是单一圆盘,Euler 数 −384,uv 范围 210×272 对世界 83×103 mm,尺度 ≈ 2.6×),所以只作"保角可达"的证据,不是最终指标。检查点 2 若选 B,先重做干净的中面网格(等值面抽取 + 重网格化)再取数。
* **窗口**:孔径(窗内切球)p05 只有 1.2–2.0 mm,是胞元边界交汇处的细缝(圆角 2.5 mm 抹不掉);< 5 mm 的窗占 26–46%,**这与 #11 的出粉要求有冲突**,不是几何 bug。c3 的窗更小(拉长 + 14 mm)。
  处理方向:`fillet_mm` 加大、胞元 ≥ 17 mm、小窗封堵(把 < 阈值的窗并入实体)作为可选后处理,封堵后要再查封闭空腔。
* 封闭空腔:补丁上 6–12 个体素级气泡(#14 的 `fill_sealed` 安全网会填),补丁没有鞋底故不能当整鞋结论。
* 耗时/内存:补丁 8.2 M 体素 3–5 s、1.5 GB;整鞋 0.5 mm 体素约 5–8× 体素数,0.3 mm(杆 1.2 mm)约 4× 以上,仍在 #14 已验证的 7 GB 量级内,需检查点 2 实测。

## 8. 风险与未知(检查点 2 前需要决定/验证)

1. **参数化路线(要你选)**:A 解析图便宜但 σ 不降;B LSCM 保角但要干净网格 + 最近点查询 + 接缝/极点工程。我倾向 B(鞋筒)+ 极点收口环。
2. **脚尖/脚跟极点**:ρ → 0 处原型用 `rho_floor_frac = 0.55` 夹住,没有解决极点;检查点 2 做收口环 + 放射杆,需要在整鞋上看效果。
3. **窗口 < 5 mm**:见 §7,#11 结果出来前,默认只报告(`enforce_opening = false`),与 #14 一致。
4. 鞋面与鞋底接缝:杆在鞋底外沿环处如何收到环上(节点圆角),概念图是连续的;需要整鞋验证。
