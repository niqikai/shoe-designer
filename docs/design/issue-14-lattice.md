## 2. 规则

**表示。** 仍是 φ_shoe < 0 为实体的 SDF。晶格在一张**细网格**(各向同性 0.3 mm,只包住鞋的包围盒)上算:粗场(h = 1.0)按 x 平面逐张三线性重采样,
每张平面上算晶格,拼成一张细场再 marching cubes。峰值只有最后那张细场(约 0.7 GB)加几个同尺寸临时数组,**不在整鞋上一次分配多个大数组**。

**鞋底区 Z(φ_Z < 0 为区内)** 由粗场构造:

```
φ_Z = max( 侧向(列)距离 , z_底 + 外底蒙皮 − z , z − (z_顶 − 内腔蒙皮) , 内腔蒙皮 − φ_C )
φ   = max( φ_shoe , min(−φ_Z , φ_晶格) )          区内是晶格,区外保持实心
```

* z_底 = 该列第一段实体的底;z_顶 = min(内腔最低点,该列实体顶);内腔外的列取最近内腔列的地板高度。
* 芯厚(z_顶 − 蒙皮 − z_底)< `core_min_mm`(3)的列保持实心;宽度 < `open_mm` 的小岛(形态学开运算)保持实心;
  **没有接到鞋外面的晶格岛也保持实心**(否则必然封死)。
* 区的侧边向外延伸 `edge_extend_mm`(4),所以鞋底侧面是开放的晶格,而不是一层薄膜;延伸部分的芯厚不得小于 `core_min/2`。
* 外底蒙皮上的出粉窗:`φ = max(φ, min(−hole, −lateral, z_底 − z))`,只在鞋底区列内开孔。

**杆状晶格的距离**(闭式,不查树):BCC 利用胞元的反射对称,折叠后只需到一根线段(胞心 → (+,+,+) 角)的距离;simple cubic 取三族棱的最小值。
测试里用暴力枚举所有杆核对。杆径 = 2r,r 取自密度→半径表(周期胞元的距离场分位数),杆中段实测半径与设定值相差 ≤ 1 体素(测试)。

**鞋面两种形态**(B)。外皮 = 内腔向外偏移 T(`offset_field` 把 S4 只在内腔外几 mm 精确的 φ_C 用体素距离接到 > 2.5 mm 外),
body = 外壳(0 ≤ φ_C < T)在鞋口线以下 + 内腔地板下 12 mm 的底板;底板套 A 的晶格,壳替换为:

1. `knit` 薄壳(T = 1.8 mm):两族纱线,管径 1.6 mm,沿壳中面(φ_C = T/2)按螺旋 `f = R0·θ ± s·x` = 常数 走(θ 绕脚长轴,绕一圈纱线数取整保证闭合)。
   到纱线的距离按世界坐标算到**曲线**:`d² = (a² + b² − 2ab·c) / (1 − c²)`(a、b 是到中面和到等 f 面的有符号距离,c 是两面法向夹角余弦),
   所以是真正的圆截面管,不是在曲面参数里画线;`1 − c²` 下限 0.12(纱线几乎贴着面走的地方变成不超过约 3 倍宽的带)。鞋口一圈 `rim_mm` = 8 和底板上 2 mm 保持实心。
2. `volume` 体晶格壳(T = 7 mm):gyroid 片(厚 1.4 mm,胞元 8 mm,世界坐标)或 BCC 杆,两面都不加蒙皮(两面都封会把片封成封闭腔)。

不做随形坐标系,不做脚垫小孔底板的图案(脚垫是实体蒙皮)。

## 3. 检查

| 检查 | 做法 | 位置 |
|---|---|---|
| 杆径 | 构建时 `2·r_min ≥ max(strut.min_diameter, process.wall_min)`,含密度表所有节点、脚垫放大、纱线径、gyroid 片厚;不满足抛 `LatticeError`(没有杆径的密度,例如 4 mm 胞元 + 0.22 占比,会被拒) | `check_radii`、`check_sole_params`、`check_upper` |
| 体素 | `voxel ≤ 实际最细杆径 / voxel_ratio(4)`,1.2 mm 杆 → 0.3 mm;h = 1.0 会被拒 | `check_voxel` |
| 蒙皮 / 出粉窗 | 蒙皮 ≥ 最小壁厚;窗 ≥ `max(powder.min_opening, process.min_channel)` | `check_sole_params` |
| 贯通孔径 | 周期晶格里一个球能从块的一面走到对面的最大直径,和最大空洞直径;`enforce_opening = true` 时不够就拒绝(默认只报告) | `pore_report` |
| 封闭空腔 | `process.sealed_cavities`(细场上)、导出 STL 上的内壳数(`mesh_inner_shells`);设计本身不应留封闭腔,另有安全网 `fill_sealed`:把残留的体素级气泡填实并报告 | `lattice.sealed`、`fill_sealed` |
| 出粉可达 | 一个直径 D 的球能从鞋外走到的范围;报告鞋底芯里它走不到的空气占比(D = 1 / 2 / 3 / 5 mm) | `powder_access` |
| 薄料 | **不用 `audit.wall_thickness`**:它沿内法线打射线,碰到晶格里任何杆都当薄壁(杆径 1.2–2 mm 全被判为薄壁),对晶格没有意义。改为体素上的形态学开运算:半径 `d_min/2 − h/2` 的球进不去的实体占总实体的比例 | `thin_material` |

薄料的比例主要来自晶格被鞋底侧面和蒙皮切出的尖角(见 §5),不是杆径不够(杆径靠参数检查保证)。

## 5. 已知限制

1. 鞋底晶格只有 1–2 层胞元;侧面是被鞋底外形切开的杆端,`thin_material` 约 0.85%(鞋底)、2.8%(鞋面壳,切在鞋口实体边和底板上)。
2. BCC 的孔径与 ≥ 5 mm 出粉要求冲突(§4)。出粉窗只能保证有出口,不保证窗里面的清粉;**要不要改 simple cubic 或加大胞元,以 #11 为准**(试件两种都导出了)。
3. 鞋面 knit:每圈纱线数按脚腔截面周长取整(32),纱线间距随半径变化;脚尖顶端纱线收束成漩涡;`1 − c²` 下限处的纱线是宽带。
   没有加强鞋头、后跟、鞋带孔。Z 向强度、回弹、舒适度都没分析。
4. 鞋面壳的外皮只靠鞋楦偏移 T,`phi_C` 的松量决定鞋腔;没做实际穿着校验。壳的底板 12 mm、边缘用 1 mm 粗网格定形,底视图有台阶。
5. 趾端方向由内腔最宽端判定(`toe = "auto"`),不是鞋楦标注。
6. 晶格相位对齐到区的包围盒和最低芯底,不随鞋底曲面走;鞋底翘起处(脚尖)杆是斜切的。
7. 没有实现 Kelvin;gyroid 厚度是一阶近似(|g|/|∇g|),测量值未做独立验证。

## 7. 与旧设计的差异

* 旧 M0 把鞋底孔隙封成封闭腔(反例):这里用侧向开放、出粉窗、孤岛过滤和 `sealed_cavities` 检查保证 0。
* 旧设计假设出粉孔喉 2–4 mm 即可,与用户给的 SLS 参考表(≥ 6–8 mm 自动清粉)冲突;这里孔径、窗径、`enforce_opening` 都是配置,默认只报告,**以 #11 为准**。
* 旧设计用 0.5 mm 体素;这里细网格 0.3 mm 且由检查强制(≤ 杆径 / 4)。
* 旧 M1 的"边界节点"没有做:杆在蒙皮平面和鞋底侧面处被直接切断并并入蒙皮。
* 旧 PR #3 的鞋面只做表面图案;这里额外探索了鞋面直接做成晶格壳(不依赖模板外皮,#44 的混搭仍不做)。
* TPMS 只用在鞋面体晶格形态(gyroid);鞋底按旧设计结论用杆状。
