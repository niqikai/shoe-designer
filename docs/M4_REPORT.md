## 可用入口

`python3 tools/apply_edit.py '口语要求'` 一次完成解释、关联截断、精确备份、版本记录、Blender 生成、制造校验、渲染和中文／JSON 报告。默认输出 `out/m3/`，无需 API 密钥。对话层使用系统 Python 3.9；Blender 5.2.2 LTS 使用内置 Python 3.13 及项目几何依赖。

```sh
python3 tools/apply_edit.py '鞋头再圆一点，脚跟再软一点' --dry-run
python3 tools/apply_edit.py '鞋头再圆一点，脚跟再软一点'
python3 tools/apply_edit.py '撤销'
python3 tools/apply_edit.py '回到第4版'
python3 tools/apply_edit.py '对比上一版'
python3 tools/apply_edit.py '对比第4版和第7版'
python3 tools/apply_edit.py '导出打印文件'
```

也支持 `--set heel_sole_mm=27`（可重复）、`--patch patch.json`、`--undo`、`--restore v004`、`--compare 4 7`、`--list`、`--json` 和 `--out out/my-design`。`--dry-run` 只解释有效参数与实际截断结果，不创建备份、锁、输出或运行 Blender。本轮实际试用“鞋口高度999毫米”得到低帮上限 85 mm 的明确截断提示，当前设计仍为 75 mm。

`designs/current.json` 仍是唯一设计真相。参数变化前逐字节备份 `history/v###.json`，追加 `CHANGELOG.md` 和 `operations.jsonl`，保留修改理由、参数差异、前后哈希与撤销父版本。版本号递增；撤销和恢复也创建新版本。连续撤销按实际修改的父版本继续回退。参数没变化时只重新生成，不创建空版本。

## 实际演示结果

| 版本 | 操作和有效变化 | Blender 耗时 | 最小采样弦长 | 薄点／缺测 | 结论 |
| --- | --- | --- | --- | --- | --- |
| v005 | “鞋头再圆一点，脚跟再软一点”：圆度 0 → 0.03，高度倍率 1 → 1.02，脚跟目标密度 0.32 → 0.27 | 19.65 秒 | 1.032 mm | 1 / 0 | 制造失败，退出 2；没有 STL／GLB |
| v006 | “撤销”：恢复 v004 的造型和密度 | 19.49 秒 | 1.336 mm | 0 / 0 | 必要检查通过，带警告候选 |
| v007 | “导出打印文件”：仅 `preview` → `export`，采样 0.8 → 0.5 mm | 48.60 秒 | 1.848 mm | 0 / 0 | 必要检查通过，带警告精细候选 |

每轮最终网格均做 192,000 次面积分层测厚。v005 在约 `(-40.26, 130.22, -7.65) mm` 检出 1.032 mm 弦长，低于 SLS 1.2 mm 门槛，因此保留 PNG／诊断、阻止导出。没有放宽门槛、忽略薄点或为了演示修改几何引擎。晶格共享周期受分区密度影响，参数在范围内也不保证某个造型制造通过。

v005 的有效参数已逐字节备份，v006 撤销时保留失败历史和实际预览。当前 v007 与 v004 的设计参数差异仅为版本号和采样档位。另用“重新生成”写入 `out/m3-export/`，没有新增版本；该目录与默认目录均对应 v007，几何与制造测量一致。

## 当前制造结果与看图

当前精细候选是单个封闭实体，2,494,004 个三角形，体积 416699.2 mm³，当前浮点方法检出的非流形、退化、重复与自交均为 0。制造厚度的薄点和缺测均为 0。已亲自打开四视图、剖视图、设备摆放图，以及 v005 失败诊断图；未观察到明显穿模，鞋内足底、连续收口与既有比例保持。预览不替代制造或穿着验证。

高精度检查检出 59 处分离、满足 4 mm 保守净空路径的中底出口，宽孔中心可达比例约 98.344%，仍有 3512 个宽孔中心没有通过同等净空通路到达外界。这个比例不是实际清粉率，保留排粉警告。

推荐绕 Z 转 35°，打印姿态尺寸约 204.891 × 243.920 × 90.908 mm，在 250 mm 三轴设备中留出项目要求的余量。XY 两側各 2 mm，最低 Z=0，两份 Z 余量留在上方；未缩小鞋码。实际打印应使用 `_print` 文件并在设备切片软件复核。

TPU 牌号、具体设备、工艺补偿及实际清粉尚未验证；回弹、重量、舒适度和稳定性只作为设计倾向。建议先打印脚跟局部样测试清粉、尺寸及反复压缩。本轮没有生成或打印局部样件。

## 验证

本轮 **93 项测试通过**：65 项纯 Python（24 项既有参数、41 项 M4）、16 项制造与收口、9 项设备摆放、3 项实际导出集成。

M4 的临时项目测试覆盖复合口语、文字顺序、中文数值和百分数、关联限幅、材料与几何意图区分、未知／否定要求不部分执行、JSON 补丁类型、精确备份、连续撤销、历史恢复、旧版默认补齐、版本递增、无写入预检、无参数变化、锁冲突、写入失败恢复、历史缓存缺失／损坏、制造失败和异常导出报告清理。测试后端只验证调用协议；真实几何另由上述 Blender 演示和集成测试验证。

实际精细 STL／GLB 重新导入，原姿态及 `_print` 姿态网格健康、毫米／米单位、刚体变换和边距往返均通过。导入后的 STL 独立进行 **384,000** 次测厚，最小采样弦长 **1.699880 mm**，薄点和缺测均为 0；9 个足底射线最大偏差 **0.004373 mm**。有限采样依然不能证明连续全表面的最小壁厚。

原 ZIP／raw 在生成及集成测试前后校验一致。代码、参数、历史和文档纳入 Git；源素材、生成网格、图片、报告缓存、进程锁与日志继续忽略。只读代码复查发现的异常导出路径、异常制造报告及不完整对比缓存处理已补齐，并以临时夹具复验。
