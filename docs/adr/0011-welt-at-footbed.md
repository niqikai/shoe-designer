# 欧氏与随形晶格在 Footbed 高度以实体 Welt 衔接

鞋底坐标系（欧氏，C = 10）与 Shell 坐标系（随形，(L_s, 8, 4)）在 Footbed 高度以一条实体 Welt（沿条）衔接：Welt 是位于 Footbed 高度、从 Footbed Edge 延伸到 Shoe Body 外表面的实体带，默认厚 1.5 mm（Override 1.5–3 mm **[初值]**）。Welt 以上的全部 Shoe Body（含 Sole Envelope 高出 Footbed 的侧壁）一律用 Shell 的随形晶格，随形坐标在 d_Last > Wall Thickness 处照常延续；Welt 以下一律用欧氏晶格；两侧在 Welt 中面硬切换，接缝藏在实体内。不做场混合，也没有 `cross_frame_width_mm`。原因是两张网络没有公共结构：任何混合都要新生 Ligament，而 Sole Envelope 侧壁与 Last 之间只有 4–6 mm 厚的重叠柱，容不下 C = 10 的鞋底网络，规格的混合会使接缝段上下完全脱开，且现有校验看不到。侧壁在 Welt 以上归 Upper 或 HeelCounter。

## Considered Options

每行为 4 组 ρ、4 种方位、6 种相位合并的 96 个窗口（e = 6 为 144 个）；采用方案另在 e = 4 与 6 mm 上共 336 个窗口全部通过，接缝瓶颈等于纯 Shell 基线，孤岛、空腔、悬挂材料、困粉均为 0。

- **规格混合**：φ = (1 − w_x)·φ_sole + w_x·φ_shell 有三处独立失败，改 W、方位、ρ、相位都无法消除。
  - 新生与消亡：均匀 w 扫描显示 w_x ∈ (0.40, 0.75–0.90) 为死区，内部最小颈厚 0.00–0.12（4 组 ρ 的最小值），死区内 20–85 % 的晶格材料是薄壁。机制与 ADR 0010 相同。
  - 密度塌陷：两侧各用自己的阈值 c(ρ)，混合后无人重标定，w ≈ 0.5 处晶格材料跌到两端均值的 55–65 %，出现孤岛与只靠细特征挂着的碎块。
  - 接缝脱开：17–27 % 的 30 mm 接缝窗口里上下之间完全没有材料通路（最宽通路瓶颈为 0）。原因是重叠柱：Last 与 Sole Envelope 侧壁之间只有 4–6 mm，里面是 C = 10 的鞋底网络，接缝沿鞋底晶格轴（0°、45°、90°）时该薄片里出现 1.5 mm 厚的空层并沿接缝重复。窗口内没有薄颈，全局分量数仍为 1，现有校验全部看不到。
- **没有公共网络**：鞋底的 C = 10 网络被切成 4–6 mm 厚的片，Shell 的网络恰好一个 Cell 厚，周向周期在 s 上均匀而鞋底相位沿接缝漂移。两网络间的任何映射要么是同伦（必然新生 Ligament，ADR 0010），要么是坐标形变 (1 − w)X_e + wX_c，其剪切项 (X_c − X_e)⊗∇w 沿 620 mm 接缝无界增长，即 ADR 0002 的相位畸变。为带内标定 c 可以消除密度塌陷，消除不了新生。
- **(a) 硬界面加裁切残边豁免**：Cut Edge 是自由表面上悬着的楔，而内部界面上的亚毫米接触是两张网络之间仅有的连接，把它们豁免在物理上不成立。证据：瓶颈为 0、孤岛、最多 28 mm³ 材料挂在亚毫米接触上，两截面的重叠面积只有 4–6 %；每 10 mm 接缝约 0.6 根薄 Ligament。重叠斑块中 36–46 % 的等效直径低于 1 mm，最小 0.02 mm。
- **(d) 光滑并集加抬高阈值**：两张网络擦边接触，颈厚降到 0（同 ADR 0010 的 a2）；ρ 加 0.10 也没有消除。
- **(b) 实体接缝于 z = H**：每一根到达实体的 Ligament 都在实体处满截面熔合，颈厚问题解决；但鞋底一侧仍是 C = 10 网络的 4 mm 薄片，薄片为空处接缝仍脱开（6–12 % 的窗口），问题在重叠柱，不在接缝位置。
- **(e) Welt 于 Footbed 高度**：让两张网络在各自都是完整网络的地方相遇，并把接触藏进实体。Footbed 高度以下，鞋底是 20 mm 以上厚的完整三维网络；以上，随形网络直接向外延续到包络面（d_Last 至 e），不产生新生。b = 1.0 mm 时有一处 0.84 mm 的内部读数，故下限取 1.5 mm。
  - 与 (b) 的区别：(b) 的实体接缝仍处在 4–6 mm 的重叠柱顶端，鞋底一侧只有一片薄片；(e) 把重叠柱整体划给 Shell 坐标系。
  - 排粉：Welt 是横向实体带，其截面两端开放；Welt 以下经侧壁开放面与 Footbed 排粉，以上经两个表面排粉。困粉 0、空腔 0。
- **端部受限读数**：采用方案的内部颈厚达标，但 Welt 擦着晶格处的读数会下探到 0，需要新的 10.2 规则（ADR 0009），否则 Welt 与现有 Skin 同样被误判为薄壁。

## Consequences

- FullLattice 允许的实体多一种：Rim、Skin 与 Welt。
- 坐标系判据：z > z_W(p) 且最近的 Last 点不在 Footbed 面上的点属于 Shell 坐标系，其余属于鞋底坐标系。Footbed 正下方的点（含足弓处 z 高于 z_W(p) 的点）一律属于鞋底，Zone 判定与场切换用同一判据，鞋底内部因此没有未被 Welt 覆盖的硬界面（否则就是 (a′)）。
- 10.2 增加端部受限判定（被边界或实体限制的端部站点不参与颈厚，其读数归入裁切残边或实体接触，soft；Ligament 仍按其余内部站点判定）和 hard 的悬挂材料检查（1 mm 闭球开运算）。两者的阈值（1.0 mm、0.1 mm、1 mm³）是首次估计。这条规则在没有 Welt 时也需要：字面的 0.5 mm 站点排除使致密 Shell（ρ 0.32 / 0.35）有 20 % / 14 % 的材料读作薄壁，默认 HeelCounter 单项约占全鞋 1.1 %；Outsole 晶格擦着 Skin 约占 0.7 %。规则只在后处理中近似验证过。
- 增重：Welt 截面约 (r_c + e)·b ≈ 8 × 1.5 = 12 mm²，每只鞋增加约 7–13 cm³ 实体，即晶格材料的 +4–7 %。
- Welt 与 Rim 一样是不可拉伸的实体条：它位于前掌中性轴上方约 11 mm，约 35° 弯折时压应变约 20 %，会局部提高弯折刚度并可能起皱。P1 候选是分段或波纹 Welt，须先通过本 harness。
- 外观上有一条贯穿鞋身的 1.5 mm 实体线，类似传统的沿条或围条。
- 实现成本低：去掉 w_x 混合与 `cross_frame_width_mm`；z_W(p) 取 `footbed_edge` 上最近点的 z（已在 `landmarks.json`），加一个坐标系切换和一个实体 SDF；随形坐标在 Footbed 以上 d_Last > Wall Thickness 处的查询由 5.5 的最近点查询承担。
- `heel-transition` Crop Build 改为以 Welt 为中心，复核实体接触与悬挂材料；15.1 增加 Welt 补丁测试。
- 取代 ADR 0010 的"遗留风险（跨坐标系过渡）"，修订 ADR 0005 的相应后果。
