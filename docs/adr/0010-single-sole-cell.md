# 鞋底只用一个 Cell，Grading 与 Transition 只改 ρ

鞋底（Outsole 晶格层、Midsole、Footbed Layer）共用同一个欧氏 Cell C（默认 10 mm，Override 8–12 mm），层间的 Grading 与 Transition 只改变等值面阈值（ρ），不改变周期。原规格在 Outsole 与 Footbed Layer 用 C/2，并以 C 与 C/2 两个 gyroid 场的线性混合过渡；实测表明这种混合不可打印。C 网络每 C³ 有 12 根 Ligament，C/2 网络有 96 根，任何从一个连续地走向另一个的路径都必须新生 Ligament，新生者颈厚从 0 起、之后才变粗。规格混合的新生点在 w* ≈ 0.52（ρ 0.15–0.50 均如此），新生 Ligament 要到 w ≈ 0.66–0.84 才超过 1.0 mm，死区为 w ∈ (0.52, 0.69–0.84)。按 8.2 的过渡宽度，Outsole↔Midsole 带内颈厚 < 1.0 mm 的宽度为 0.4–0.7 mm，Footbed Layer 的 Grading 带为 0.6–1.4 mm。22 mm 前掌鞋底平板（4 种晶格相位）的薄壁占比为 9–10 %，Midsole 薄处（T 约 5.6–7.5 mm）的平板达 34–44 %，而 hard 限值是 1 %。Resolver 原定的检查点 w ∈ {0.25, 0.5, 0.75} 跳过了这一区域（w = 0.5 仍在新生之前，颈厚 1.6–2.3 mm），所以它会放行随后被 Printability Check 判失败的设计。

## Considered Options

均为 C = 10、颈厚单位 mm，数据来自 `.scratch/neck-acc/blend/`（均匀 w 扫描 183 个 (w, ρ) 格；平板 128 块）。

- 规格混合（线性 φ 混合，共用阈值 c(ρ, w)）：均匀胞元最小颈厚 0.11，平板 0.16–0.30，薄壁占比 9–10 %。拒绝。
- (a1) 逐场偏移加光滑并集（用腐蚀淡出各自的晶格）：w ∈ (0, 1) 内最小颈厚 0.0–0.27，薄壁占比 26–29 %。两张网络互相擦边，更差。拒绝。
- (a2) 重叠带：两个完整晶格的光滑并集，带两端硬切换：最小颈厚 0.0（ρ ≤ 0.30）至 0.91（ρ 0.45），薄壁占比 16–30 %；两网络擦边接触使颈厚趋于 0。拒绝。
- (b) 相位平移或镜像 C/2 场，使 C 与 C/2 的节点对齐：死区仍在 w 0.50–0.81，最小颈厚 0.34（平移）/ 0.43（镜像），薄壁占比 9.7 %（ρ 0.20）。不存在能让 8 个 C 节点都落在 C/2 材料内的平移（最多 2 个重合），且两个场的傅里叶壳不相交，平移无法使它们相关。拒绝。
- (c) 单一界面（W → 0），可加 1 mm 实体连接板：最小颈厚 0.13（无板）/ 0.26–0.31（有板），薄壁占比 10.5 % / 5.5–7.6 %。两个被切开的网络的接触面积可小到 0，晶格擦着板；板还在内部形成实体片，阻断排粉并在 8.1 不允许的位置形成 Skin，与 FullLattice 和 ADR 0007 冲突。拒绝。
- (d) 随 w 抬高阈值：即使 ρ 到 0.50，w = 0.531 处颈厚仍只有 0.14；w 0.6–0.75 范围 ρ 要多加 0.15–0.30（该带约两倍刚度）。无法消除新生，且代价大。拒绝。
- (e) 调整过渡宽度 W：W 从 0.01 到 6 / 8 mm，最小颈厚 0.13–0.36，薄壁占比 10.5–19 %（规格 W 为 11.1 %）。Δw 固定，带宽随 W 缩放，W → 0 退化为 (c)。拒绝。
- (f) w 跳变，越过 (0.5, 0.875)：最小颈厚 0.0，薄壁占比 10–15 %。等于两种拓扑之间的硬界面，即 (c)。拒绝。
- (g) 单一鞋底 Cell，只改 ρ（采用）：C = 10 的晶格内最小颈厚 2.08–2.95，C = 8 为 1.67–2.36；薄壁占比 0；Pore Throat：C = 10 时 Outsole（ρ 0.35）≥ 5.15、芯部 ≥ 5.4（firm 0.305）；0 个 Island、0 个封闭腔。共 48 块平板（C = 10 与 8，前掌堆高 22 与 15 mm，ρ_mid 0.15 / 0.20 / 0.27，4 种相位）。

没有任何混合能奏效：从 C 细化到 C/2 必须增加把手（Ligament 数从 12 增到 96），在连续的场族中，新把手出现在某个临界点穿过等值面的时刻，新 Ligament 在颈厚 0 处诞生。空间 Grading 只是把 [w*, w_hi] 摊开成宽 W·Δw 的带；缩小 W 就变成硬界面，其接触面积在任何扫过各晶格相位的边界上都会趋于 0。即使网络嵌套（Schwarz-P 的 2:1 包含 C 网络为子图），多出的 C/2 边仍须新生。能把新生藏起来的只有实体（Skin 或连接板），即 (c)。

## Consequences

- **可行域**：单一 C 下所有档位可行的范围约为 C ≈ 7.4–12 mm（颈厚下限：soft 下沿 ρ 0.125 给出 ≈ 1.85·C/10 ≥ 1.05，要求 C ≥ 5.7；孔喉上限：firm 上沿 ρ 0.305 给出 5.44·C/10 ≥ 4.0，要求 C ≥ 7.4；Outsole 在 ρ 0.35 时颈厚 3.45·C/10、Pore Throat 5.15·C/10，远在薄层限值之内）。Override 范围 8–12 mm 整体可行，默认 C = 10 无需 Adjustment；C ≥ 10 时 Outsole 还满足部分 SLS 供应商要求的 ≥ 5 mm 晶格间隙（9.2）。
- **代价**：Footbed Layer 只是更密（ρ + `rho_delta`），不再更细；Outsole 也不再有更细的孔。若脚感或抓地确实需要更细的脚床或外底，作为 P1 研究，必须先通过本 harness：候选是层内有界的仅 z 向仿射压缩（同一网络，不产生新 Ligament，需要给 ADR 0002 开例外），或显式设计的杆件晶格。
- **Feasibility Table 变小**：去掉混合权重 w 维度与混合场的 c 标定，欧氏部分是 ρ 的一维表，c、最小颈厚、Pore Throat 按 C 缩放；表的大小与生成时间约缩小 5 倍。Resolver 的"放大 Cell"步骤只放大这一个 C，不再有可能低于 Outsole 颈厚限值的 C/2。
- **检查点**：Resolver 在 Transition 与 Grading 带内只检查带的两端，因为 Neck Thickness 与 Pore Throat 对 ρ 单调。
- **孔喉分级**：薄层改为 Shell 中各 Zone、Footbed Layer 及其 Grading 带、Outsole 及其过渡带，以及 Midsole 中 T < C 的点（ADR 0007）。Midsole 薄处不再有特殊处理。
- **遗留风险（跨坐标系过渡）**：φ = (1 − w_x)·φ_sole + w_x·φ_shell 混合的是 C = 10 的欧氏网络与 (L_s, 8, 4) 的随形网络，是两张不同的网络，同一新生机制使它预计在宽约 Δw × `cross_frame_width_mm` 的带内产生薄 Ligament。必须在 `heel-transition` 的 Crop Build 之前，用与本 ADR 相同的均匀 w 扫描和平板测试在 harness 中验证，可能需要豁免（按 Cut Edge 处理）、Rim 式实体接缝或使两侧网络匹配（规格 20）。
- Footbed 的 Cut Edge 处在 z = ZF − 0.55 的读数（C = 8、15 mm 堆高时 1.11–1.49，C = 10 时 2.58）属于另行报告的 soft"裁切残边"，不是混合问题。
