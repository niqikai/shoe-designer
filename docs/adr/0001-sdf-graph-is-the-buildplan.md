# 几何内核用 SDF 场景图，图本身就是 BuildPlan

整只鞋表示为一个有向无环图（GeometryGraph）：叶子是基本体、鞋楦采样场和晶格，内部节点是布尔、平滑并集、偏置和裁切。图的规范化 JSON 计算出 `graph_hash`，它就是 BuildPlan，可存档、可重建。求值器在任意点上确定性地返回带符号距离；网格只是对图按某个区域和分辨率求值后的产物。

## Considered Options

- **B-Rep（OCCT / build123d），即 PR #2 的路线**：曲面精确、能出 STEP。但上万根杆或 TPMS 的布尔运算慢、易失败、内存不可控；PR #2 已经遇到整只鞋楦偏置失败、放样不可行，只能针对单只鞋楦调参。拒绝作为主内核。
- **网格直接构造（逐根杆建网格再做网格布尔）**：可以用 manifold3d 做稳健布尔，但渐变、平滑过渡和随形都要在网格层面重新实现，且节点处的圆角难做。拒绝。
- **隐式场 + 自定义流水线，即 PR #1 的路线**：方向正确，但 PR #1 把阶段 A/B、Shape Bundle、BuildPlan 分别定义成多种格式。拒绝其复杂度，保留其内核选择。
- **SDF 场景图（采用）**：一种表示同时服务预览、整鞋、Crop、Coupon；新晶格类型只是新节点。

## Consequences

- 输出是三角网格（STL，之后 3MF），不是 STEP。需要精确 CAD 的场景（开模、实体件）不在本路线范围。
- 节点类型是白名单，新增节点要升 `graph_version`。
- 采样场节点（鞋楦）在图里以内容哈希出现：源文件 sha256、采样参数、采样数组的 sha256 都计入 `graph_hash`，否则 BuildPlan 无法复现。鞋楦数据本身不入库。
- 确定性要求见 ADR 0005：同一点在不同分块下求值结果逐位一致。
- 平滑并集等运算会让 SDF 不再是严格的欧氏距离，只保证 Lipschitz ≤ 1。跳过空块时依赖这一点，所以每种解析节点都必须保证 Lipschitz ≤ 1，并有单元测试。几类容易破坏这一点的情况要专门处理：
  - 两端半径不同的杆要用 round-cone 公式，不能用"线段距离减插值半径"；
  - 高度场不用"除以 √(1 + 最大坡度²)"的全局缩放：这样得到的是距离下界，在平坦处会把距离压小十几倍甚至更多（见下条）。改为把高度曲面三角化后，像鞋楦一样采样它的真实距离（`HeightSurfaceField`，实现计划 M0.3/M0.4）；
  - 变形（尺码）作用在鞋楦网格上后重新采样，不在 SDF 上直接复合变形；
  - 定义在表面参数坐标上的图案（ADR 0006）按参数化的 Jacobian 和曲率给出 Lipschitz 上界；不能保证 ≤ 1 的公式不进白名单；
  - 采样场有插值误差，由 ADR 0005 的安全系数吸收。
- **Lipschitz ≤ 1 只保证跳块安全，不保证场值是毫米距离。** 偏置、壳、平滑并集的 k 和厚度检查都把场值当作毫米距离用，所以每个节点在图里带一个度量属性：
  - `exact`：在用到的范围内等于欧氏距离（误差 ≤ 采样容差），如基本体、胶囊、鞋楦和高度曲面的窄带采样场；
  - `bound`：只是距离下界，如平滑并集、网眼图案、粗栅格区域。
  - 组合规则：`Intersect`、`Subtract` 的内侧（d < 0）保持 `exact`，`Union` 的外侧（d > 0）保持 `exact`，其余情况降为 `bound`。
  - 构建时检查（退出码 3）：向内偏置（收缩）要求子节点内侧为 `exact`，向外偏置和 `ShellOutward` 要求外侧为 `exact`；否则拒绝，而不是生成一个尺寸错了却能通过水密检查的网格。
