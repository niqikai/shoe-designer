# 用真实鞋楦，尺码变化靠变形，不用 Blender

鞋楦来自 STEP 或扫描网格，导入和归一化移植 PR #2 的实现（`last/loader.py`、`last/normalizer.py`）。三角化后用 libigl 计算带符号距离，在 0.5 mm 栅格的窄带内采样，作为 GeometryGraph 的叶子节点。不同尺码和楦型由少量关键尺寸（楦长、跖围、跟宽等）驱动的平滑变形（FFD 或 RBF）得到。变形作用在鞋楦网格上，变形后重新采样 SDF；变形参数参与哈希。不在 SDF 上直接复合变形，因为那会破坏 Lipschitz ≤ 1（ADR 0001）。

## Considered Options

- **Blender 程序化控制笼，即 PR #1 的路线**：参数完全可控，但形状真实度要等人工目视签收；引入 Blender 子进程、版本锁定、Shape Bundle 契约和一整类失败码。拒绝。
- **只用一只固定鞋楦**：最简单，但无法覆盖尺码。仅作为 M0 的起点。
- **真实鞋楦 + 变形（采用）**：形状真实度来自实物；变形是平滑映射，不改变拓扑。

## Consequences

- 鞋楦文件和由它派生的几何都只留在本地，不入库、不上传第三方（沿用 PR #2 的 `asset_provenance` 规则）。测试用解析合成鞋楦（圆角体），不依赖授权资产。
- **授权**（2026-10-16 确认）：现有鞋楦文件头为 CC BY-NC-ND 4.0，不允许商用，只用于开发阶段。由它生成的任何几何都只在本地，不对外展示或分发，也不发给打样服务商；需要外部打印的整鞋必须换用自行设计的鞋楦（实现计划 M4、H7）。正式使用的鞋楦由你自行设计；导入与变形接口按通用鞋楦设计，换楦只需换输入文件和归一化配置。
- 依赖 build123d / cadquery-ocp（STEP 读取，LGPL 的 OCCT 内核）和 libigl（MPL-2.0）。OCCT 只在导入阶段使用。build123d 0.10.0 还需要固定 `ocp-gordon==0.1.17`（0.3.x 依赖 OCP 8，与 build123d 0.10.0 要求的 cadquery-ocp < 7.9 冲突；0.1.17 是 PR #2 用过的版本，见 `pyproject.toml`）。
- **带符号距离的定号（M0.3 实现时改定，M0 评审确认）**：不用 winding number，改用角度加权伪法向（Bærentzen & Aanæs）：libigl AABB 求最近点，按重心坐标判断最近点落在面、边还是顶点，取对应的法向定号。它对闭合、流形、取向一致的网格是精确的，而 `last_to_mesh` 在三角化后逐项检查了这些条件（水密、每条边恰好两个反向三角形、单连通、体积为正），不满足就以退出码 4 拒绝。实测 winding number 在 1 万三角形的网格上只有约 4,000 点/秒（fast winding number 约 20,000 点/秒），伪法向快约 20 倍。winding number 仍作为 `MeshSDF(sign="winding_number")` 保留，用于没经过检查的网格。
- **误差（M0.3 实测，M0 评审复核）**：三线性插值表示不了距离场梯度的间断（中轴、折痕），所以误差上限按"离中轴多远"分开写。细栅格窄带：离中轴 > 1 mm 处 ≤ 0.05 mm（合成鞋楦实测 0.021 mm），包括中轴附近最大 0.146 mm（半球鞋楦边缘）；粗栅格区域：离中轴 > 4 mm 处实测 0.058 mm，包括中轴附近 0.990 mm，接近 1 mm 的验收上限。高度曲面采样场同理：离折痕处 0.028 mm，含折痕 0.116 mm。实现计划 M0.3 原文没有写这个排除条件，测试是按排除后的范围断言的；评审接受这一点（插值方法的固有限制，只影响中轴约 1 个体素内），并在这里写明。粗栅格只用于跳块判断和窄带外的符号，不用于任何偏置或厚度。
- 鞋楦 SDF 双层采样：0.5 mm 细栅格只存 |d| ≤ 6 mm 的窄带；2 mm 粗栅格覆盖包围盒外扩 30 mm；再往外用到鞋楦包围盒的距离（正值，是真实距离的下界）。
- 高度曲面采样场（`HeightSurfaceField`，M0.3）的实现：曲面 `z = h(x, y) + 偏移` 先在 1 mm 规则点阵上做 Delaunay 三角化，再用精确的高度函数（鞋楦网格的竖直射线求交）自适应加密，直到每个三角形的重心与边中点到真实曲面的法向偏差 ≤ 0.02 mm，或最长边 < 0.03 mm；0.5 mm 均匀栅格跟不上轮廓边缘的陡坡（R = 50 mm 半球边缘一个 0.5 mm 格子偏 0.125 mm）。无符号距离用 libigl AABB，符号取 `z − z_sheet(x, y)`，`z_sheet` 在同一组三角形上插值。这张曲面是**有限的**：只铺在足底轮廓包围盒外扩 `sheet_margin_mm` 的 XY 矩形里，场值只在这个矩形里是到无限曲面的精确距离，矩形外是到曲面边缘的距离。所以用它的图必须留在矩形内：`build_shoe_graph` 检查矩形覆盖了包络轮廓（足底轮廓 + `outline_margin_mm` + 1 mm），不满足以退出码 3 拒绝；CLI 取 `sheet_margin_mm = max(8, outline_margin_mm + 5)`（默认值 30 mm 要多花约 30 s）。
  - 网格只在细栅格窄带内提取，所以图里对鞋楦做的偏置量必须 ≤ 窄带宽度 − 1 mm，构建时检查。
  - 细、粗栅格的切换处有不超过粗栅格误差（约 1 mm）的跳变，只影响跳块判断，由 ADR 0005 的安全系数吸收；Lipschitz 测试只在细栅格窄带内做。
- 采样数组用 `.npy` 存盘，worker 以 `mmap_mode='r'` 打开共享页缓存，避免每个进程复制一份。
- 归一化方向仍是显式配置的刚体变换，不自动推断鞋头方向和左右脚。
- 授权信息的记录方式（M0 评审）：PR #2 的 loader 写的是 `license_status = "REQUIRES_PURCHASE_AUTHORIZATION_REVIEW"`，与本 ADR 的决定不一致。现在 loader 只报告文件头声明的许可（`license_declared`，如 `CC BY-NC-ND 4.0`，原文在 `license_notice`；没有声明时为 `NOT_DECLARED_IN_FILE_HEADER`），以及本 ADR 规定的项目用法 `usage_policy = DEVELOPMENT_ONLY_LOCAL_ONLY`（`local_only = true`）。这是项目约定，不是法律判断；代码不对许可作任何超出本 ADR 的判断。
