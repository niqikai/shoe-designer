# 晶格默认用杆状，TPMS 只作为可选节点

晶格节点有 `kind` 字段，取值 `strut`（默认）或 `tpms`（暂不实现）。M0 的杆状晶格按周期公式枚举查询点附近的杆，所有杆半径相同；M2 引入显式节点与杆列表（用于随形和渐变），两端半径不同的杆用 round-cone 公式。节点处的圆角用与顺序无关的指数平滑并集 `−k·ln Σ exp(−d_i/k)`，杆按固定的全局顺序求和。杆的最小壁厚就是最小杆直径，在构建 Graph 时按 ManufacturingProfile 检查。

## Considered Options

- **TPMS（Gyroid），即 PR #1 的路线**：外观连续、各向较均匀。但壁厚由等值面阈值和周期间接决定，只能事后在体素上测量；PR #1 为此设计了合并树颈厚测量（PR #1 的 ADR 0009）、困粉检查、悬挂材料检查、Cell Properties 与局部探测（PR #1 的 ADR 0012），并发现不同 Cell 尺寸无法混合（PR #1 的 ADR 0010）、跨坐标系必须加实体 Welt（PR #1 的 ADR 0011）。Gyroid 外观不是硬性要求（2026-10-16 确认），拒绝作为默认。
- **Voronoi / 随机杆网**：外观有机，但刚度离散度大，难以标定，确定性也要额外处理随机种子。延后。
- **周期杆状晶格（采用）**：先做 BCC，之后加 Kelvin（十四面体）。杆径显式；开放结构易排粉；量产晶格中底普遍采用；刚度与相对密度的关系有成熟的标定办法。

## Consequences

- 杆的薄壁检查变成参数检查：`2 × min(r) ≥ profile.min_strut_diameter_mm`，不满足时在构建 Graph 时就拒绝（退出码 3）。平滑并集只增厚，不会让杆变细。
- 参数检查管不到裁切：包络裁切和减去腔体可能切出任意薄的碎片。所以网格上仍有一项薄片检查（在体素栅格上做距离变换，统计局部厚度低于下限的材料体积）。M0 只报告；M2 用边界节点消除裁切后升为 hard。
- 体素尺寸必须 ≤ 最小杆直径 / 4，否则杆在网格上会断开；构建时检查（退出码 3）。
- 困粉检查降级：杆状晶格是开放网络，只需粗粒度地检查是否存在封闭腔（体素泛洪），不需要按孔喉尺寸逐点判定。
- M0 里被包络裁切的杆都并入外皮，不留悬空断头；M2 在包络表面布点，让杆终止在边界节点或实体皮上。
- 随形鞋面不需要切换坐标系：在鞋楦表面参数化上布节点，沿法向长出层即可，不需要 PR #1 的 Welt。
- 外观和受力连续性不如 TPMS。若以后要 Gyroid，作为新节点类型实现，并重新引入其壁厚测量。
