# 晶格默认用杆状，TPMS 只作为可选节点

晶格节点有 `kind` 字段，取值 `strut`（默认）或 `tpms`（暂不实现）。（实现说明，M0 评审：`kind` 由节点类型表达——M0 的节点是 `StrutLattice`（`topology = "bcc"`），TPMS 以后是新的节点类型并升 `graph_version`，与 ADR 0001"新晶格类型只是新节点"一致；不另设 `kind` 字段。）M0 的杆状晶格按周期公式枚举查询点附近的杆，所有杆半径相同；M1 引入显式节点与杆列表（用于边界节点和渐变），两端半径不同的杆用 round-cone 公式。节点处的圆角用与顺序无关的指数平滑并集 `−k·ln Σ exp(−d_i/k)`，杆按固定的全局顺序求和。这个指数形式只在 `StrutLattice` 的内核里使用（M0.7，`kernels._strut_lattice`）；通用的 `SmoothUnion(k)` 节点（M0.4）是另一个函数，用二次 smin `min(a, b) − k/4 · max(k − |a − b|, 0)² / k²`，按子节点顺序左折叠。两者都 ≤ min、Lipschitz ≤ 1、只增加材料，度量属性都是 `bound`；`SmoothUnion` 的偏离量 k/4 计入采样场的偏置余量（ADR 0003），晶格不对采样场求值，不涉及这一项。杆的最小壁厚就是最小杆直径，在构建 Graph 时按 ManufacturingProfile 检查。

## Considered Options

- **TPMS（Gyroid），即 PR #1 的路线**：外观连续、各向较均匀。但壁厚由等值面阈值和周期间接决定，只能事后在体素上测量；PR #1 为此设计了合并树颈厚测量（PR #1 的 ADR 0009）、困粉检查、悬挂材料检查、Cell Properties 与局部探测（PR #1 的 ADR 0012），并发现不同 Cell 尺寸无法混合（PR #1 的 ADR 0010）、跨坐标系必须加实体 Welt（PR #1 的 ADR 0011）。Gyroid 外观不是硬性要求（2026-10-16 确认），拒绝作为默认。
- **Voronoi / 随机杆网**：外观有机，但刚度离散度大，难以标定，确定性也要额外处理随机种子。延后。
- **周期杆状晶格（采用）**：先做 BCC，之后加 Kelvin（十四面体）。杆径显式；开放结构易排粉；量产晶格中底普遍采用；刚度与相对密度的关系有成熟的标定办法。

## Consequences

- 杆的薄壁检查变成参数检查：`2 × min(r) ≥ profile.min_strut_diameter_mm`，不满足时在构建 Graph 时就拒绝（退出码 3）。平滑并集只增厚，不会让杆变细。
- 参数检查管不到裁切：包络裁切和减去腔体可能切出任意薄的碎片。所以网格上仍有一项薄片检查（在体素栅格上做距离变换，统计局部厚度低于下限的材料体积）。M0 只报告；M1 用边界节点消除裁切后升为 hard。
- 体素尺寸必须 ≤ 最小杆直径 / 4，否则杆在网格上会断开；构建时检查（退出码 3）。
- 困粉检查降级：杆状晶格是开放网络，只需粗粒度地检查是否存在封闭腔（体素泛洪），不需要按孔喉尺寸逐点判定。
- **开放问题（M0 评审，2026-10-17）：M0 的鞋底并不开放。** 晶格本身是开放网络，但 M0.8 的装配把它整个包在 1.2 mm 外皮和足床板里，孔隙网络因此成了一个封闭大腔：合成鞋楦上是网格里的负体积壳（rounded 30,351 mm³），真实鞋楦（0.5 mm 体素，暂定结果）上是 269,170 mm³ 的单个不可达空腔，M0.9 的 `enclosed_cavities` 软检查把它报告为 finding。粉末床（MJF/SLS）会把未烧结的粉末封在里面，DLS 会把未固化的树脂封在里面。上面"开放结构易排粉"的论证只对晶格本身成立，对 M0 的鞋底不成立。M0 不改设计（它只是骨架）；M1 必须在以下方案里选一种并实现：侧壁局部开口（让晶格在鞋底侧面露出）、在外皮上开排粉/排液孔（位置与孔径进 profile，`requires_drain_holes`）、或部分开放的外皮（例如只保留底面和足床板）。同时把封闭腔检查改为"每个空腔都连通到外部"的检查，在 `requires_drain_holes = true` 的 profile 下升为 hard。实现计划 M1 一节列为开放设计问题。
- M0 里被包络裁切的杆都并入外皮，不留悬空断头；M1 在包络表面布点，让杆终止在边界节点或实体皮上。
- 杆状晶格只用于鞋底。鞋面改用表面图案（ADR 0006），所以也不需要 PR #1 的随形坐标系和 Welt。
- 外观和受力连续性不如 TPMS。若以后要 Gyroid，作为新节点类型实现，并重新引入其壁厚测量。
