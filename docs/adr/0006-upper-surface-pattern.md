# 鞋面用贴合鞋楦的表面图案（网眼或仿针织），不用体晶格

鞋面是一层贴着腔体外侧、厚 1.2–2 mm 的薄壳。它的结构由定义在鞋楦表面参数坐标 (u, v) 上的二维图案决定，有两类（2026-10-16 确认），**默认用仿针织**，网眼为可选：

- **网眼（Mesh）**：在薄壳上开孔，孔形可以是六边形、菱形或椭圆等，孔径与筋宽可沿鞋面渐变。
- **仿针织（Knit-like）**：用沿表面曲线走的"纱线"管体组成线圈结构，模仿纬编的线圈排布；纱线在法向上有起伏，模拟上下交织。

两类都作为 GeometryGraph 的 `SurfacePattern` 节点实现，鞋底仍用杆状晶格（ADR 0002）。

## Considered Options

- **随形体晶格，即 PR #1 的路线，也是本仓库 ADR 0002 原先对 M2 的设想**：1–2 mm 的薄壳装不下三维 Cell，杆会被裁成碎段。PR #1 为此要切换坐标系、加 Welt，复杂度高。拒绝。
- **实体薄壳**：最简单，但不透气、不柔软，不是想要的鞋面。只保留为 M0 的占位。
- **表面图案（采用）**：与鞋面的实际功能（透气、包裹、弯折）对应，参数直观（孔径、筋宽、纱线粗细、线圈密度），厚度方向只有一层，几何简单。

## 设计要点

### 表面参数化
- 取鞋楦网格中鞋面覆盖的部分，沿后跟中线切开，用 libigl 做低扭曲的展平（LSCM，必要时再做 ARAP），得到每个顶点的 (u, v)，单位与 mm 同量级。
- 网眼要在求值时查 (u, v)：把 (u, v) 和表面法向也像 SDF 一样采样到鞋楦的细栅格窄带里（ADR 0003），查询时三线性插值。窄带里离开表面的点取其最近表面点的 (u, v)。仿针织不在求值时查 (u, v)，见下文。
- 记录展平的最大面积扭曲和角度扭曲。σ_max 是"世界坐标 → (u, v)"的 Jacobian 在表面上的最大奇异值，超过 1.3 时报错，需要换切缝或分片。

### 节点的距离场
- 网眼：薄壳本身是 `s = |d_cavity − t/2| − t/2`（腔体外侧厚 t 的一层）；开孔后 `d = max(s, p(u, v) / L)`，其中 `p` 是图案的二维 SDF（筋为负，孔为正）。
  - L 是复合映射"世界点 → 最近表面点 → (u, v)"的 Lipschitz 上界：`L = σ_max / (1 − κ_c · d_max)`。κ_c 是鞋面区域内凹方向的最大主曲率，d_max 是壳外表面到鞋楦的最大距离（间隙 + t）。在内凹处，离开表面的点投影回表面时会被放大，这一项只看表面上的 σ_max 会漏掉。构建时要求 κ_c · d_max < 0.5，否则报错。
  - 除以 L 不改变零集，只保证 Lipschitz ≤ 1；场值不是毫米距离，节点属性为 `bound`（ADR 0001），不能再偏置。
  - 世界坐标里的实际筋宽 ≥ 参数筋宽 / L，最小特征检查用这个下界，不用参数筋宽。
- 仿针织：不在 (u, v) 平面里算距离。旧写法 `√((d_uv / σ_max)² + (d_n − w)²) − r` 不是到三维纱线的距离：即使 σ_max = 1，纱线沿 x、起伏 `w = x` 时它变成 `√(y² + (z − x)²) − r`，垂直于实际纱线的截面直径只有 2r / √2（r = 0.5 mm 时约 0.71 mm，却会按 1 mm 通过检查），梯度范数为 √2（数值复核结果相同）。坡度为 2 时梯度达 √5，超过跳块安全系数 1.5。整体缩放也修不好已经变细的零集。改为在世界坐标里构造纱线：
  - 在 (u, v) 平面里生成纬编线圈的中心线 `c(s)` 和法向起伏 `w(s)`，按弧长采样；
  - 每个采样点映射到世界坐标：`X(s) = S(u, v) + (间隙 + t/2 + w(s)) · n(u, v)`，S 是鞋楦表面点（由参数化反查三角形重心坐标得到），n 是该点的法向；
  - 相邻点连成线段，线段长度按弦高 ≤ 0.02 mm 选取；纱线 = 半径 r 的胶囊链，求值用 `CapsuleSet` 节点（显式线段列表 + 均匀网格分桶，固定的全局线段顺序，与 M1 的显式杆图共用）；
  - 这样距离是到真实三维管体的欧氏距离：Lipschitz ≤ 1、实际直径就是 2r，与坡度、扭曲和曲率无关。扭曲只改变线圈在世界坐标里的大小（最多 σ_max 倍），报告里给出实测的线圈尺寸范围；
  - 法向偏移不能超过内凹处的曲率半径，否则偏移后的纱线会自交：构建时要求 κ_c ·（间隙 + t/2 + max w + r）< 0.5。
- 纱线在交叉处默认用平滑并集相互熔合（只增加材料，不会让纱线变细），鞋面是一个整体。"互锁但不熔合"（类似链甲）只有部分工艺能打，工艺未定（Q2），先不做，留作选项。

### 边界与接缝
- 后跟切缝处放一条实体的后跟加强条，盖住参数化的接缝，图案不必跨缝连续。u 在切缝两侧不连续，三线性插值会在切缝附近得到无意义的值，所以加强条宽度至少要盖住切缝两侧各 2 个细栅格体素（共 ≥ 2 mm），这个范围内不使用 (u, v)。
- 领口放一圈实体 Rim，鞋面底边与鞋底外皮（ADR 0002、M0.8）熔合成一条实体带。
- 鞋带孔、鞋舌等以后作为额外的实体区域节点叠加。

## Consequences

- 最小特征检查与杆状晶格相同：纱线直径 2r、网眼筋宽的世界坐标下界（参数筋宽 / L）都 ≥ `min_strut_diameter_mm`，体素 ≤ 最小特征 / 4（ADR 0004）。纱线直径约 1 mm 时需要 0.25 mm 体素。但鞋面只占一层薄壳，窄带里的体素数可控。
- 回归测试必须包括：与 u 轴成 45° 的斜纱线、坡度为 2 的周期起伏、σ_max 接近 1.3 的扭曲区域、内凹区域。每种情形都在网格上实测垂直于纱线的截面直径（误差 ≤ 1 个体素）、做随机点对的 Lipschitz 测试，并对比跳块与不跳块的网格是否完全相同。
- 仿针织依赖 `CapsuleSet` 节点。M1 的显式杆图要先把它做出来；如果 M2 先开始，就由 M2 实现并交给 M1 复用，只实现一次。
- 鞋面刚度和弯折性能与开孔率、纱线密度的关系，要到打印阶段（M4）才能实测。在那之前只报告几何指标：开孔率、单位面积质量、最小特征。
- 默认方案是仿针织（实现计划 Q5），所以 M2 先实现仿针织；它的纱线几何和 Lipschitz 处理比网眼复杂，风险也在这里。
- 鞋楦换成自行设计的鞋楦（Q1、Q6：STEP 格式，最迟在外部整鞋打样之前提供）后，参数化要重新生成；切缝位置按约定的地标（后跟中线）自动确定，不需要手工调整。
