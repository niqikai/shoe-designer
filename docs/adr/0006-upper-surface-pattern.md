# 鞋面用贴合鞋楦的表面图案（网眼或仿针织），不用体晶格

鞋面是一层贴着腔体外侧、厚 1.2–2 mm 的薄壳。它的结构由定义在鞋楦表面参数坐标 (u, v) 上的二维图案决定，有两类（2026-10-16 确认）：

- **网眼（Mesh）**：在薄壳上开孔，孔形可以是六边形、菱形或椭圆等，孔径与筋宽可沿鞋面渐变。
- **仿针织（Knit-like）**：用沿表面曲线走的"纱线"管体组成线圈结构，模仿纬编的线圈排布；纱线在法向上有起伏，模拟上下交织。

两类都作为 GeometryGraph 的 `SurfacePattern` 节点实现，鞋底仍用杆状晶格（ADR 0002）。

## Considered Options

- **随形体晶格，即 PR #1 的路线，也是本仓库 ADR 0002 原先对 M2 的设想**：1–2 mm 的薄壳装不下三维 Cell，杆会被裁成碎段。PR #1 为此要切换坐标系、加 Welt，复杂度高。拒绝。
- **实体薄壳**：最简单，但不透气、不柔软，不是想要的鞋面。只保留为 M0 的占位。
- **表面图案（采用）**：与鞋面的实际功能（透气、包裹、弯折）对应，参数直观（孔径、筋宽、纱线粗细、线圈密度），厚度方向只有一层，几何简单。

## 设计要点

### 表面参数化
- 取鞋楦网格中鞋面覆盖的部分，沿后跟中线切开，用 libigl 做低扭曲的展平（LSCM，必要时再做 ARAP），得到每个顶点的 (u, v)，单位与 mm 同量级。
- 把 (u, v) 和表面法向也像 SDF 一样采样到鞋楦的细栅格窄带里（ADR 0003），查询时三线性插值。这样求值仍是"按栅格查表"，确定、快，也不需要在求值时找最近三角形。
- 记录展平的最大面积扭曲和角度扭曲。最大拉伸比 σ_max 超过 1.3 时报错，需要换切缝或分片。

### 节点的距离场
- 网眼：薄壳本身是 `s = |d_cavity − t/2| − t/2`（腔体外侧厚 t 的一层）；开孔后 `d = max(s, p(u, v) / σ_max)`，其中 `p` 是图案的二维 SDF（筋为负，孔为正）。除以 σ_max 是为了保证 Lipschitz ≤ 1（ADR 0001）。
- 仿针织：纱线中心线是 (u, v) 平面里的周期曲线，加上法向起伏 `w(u, v)`。记 `d_n = d_cavity − t/2`（到壳中面的法向距离），`d_uv` 为 (u, v) 平面里到纱线中心线的距离，则距离近似为 `√((d_uv / σ_max)² + (d_n − w)²) − 纱线半径`。起伏 `w` 的坡度要有上限，否则也会破坏 Lipschitz 约束。
- 纱线在交叉处默认相互熔合，鞋面是一个整体。"互锁但不熔合"（类似链甲）只有部分工艺能打，工艺未定（Q2），先不做，留作选项。

### 边界与接缝
- 后跟切缝处放一条实体的后跟加强条，盖住参数化的接缝，图案不必跨缝连续。u 在切缝两侧不连续，三线性插值会在切缝附近得到无意义的值，所以加强条宽度至少要盖住切缝两侧各 2 个细栅格体素（共 ≥ 2 mm），这个范围内不使用 (u, v)。
- 领口放一圈实体 Rim，鞋面底边与鞋底外皮（ADR 0002、M0.8）熔合成一条实体带。
- 鞋带孔、鞋舌等以后作为额外的实体区域节点叠加。

## Consequences

- 最小特征检查与杆状晶格相同：筋宽和纱线直径 ≥ `min_strut_diameter_mm`，体素 ≤ 最小特征 / 4（ADR 0004）。纱线直径约 1 mm 时需要 0.25 mm 体素。但鞋面只占一层薄壳，窄带里的体素数可控。
- 鞋面刚度和弯折性能与开孔率、纱线密度的关系，要到打印阶段（M4）才能实测。在那之前只报告几何指标：开孔率、单位面积质量、最小特征。
- 需要新的人工检查：网眼与仿针织两种外观的目视对比，并决定默认用哪一种（实现计划 Q5）。
- 鞋楦换成自行设计的鞋楦（Q1）后，参数化要重新生成；切缝位置按约定的地标（后跟中线）自动确定，不需要手工调整。
